# SM: string-stack machine for the ZF proof enumerator (spec v1)

Author: zf-framework design lead. Goal: a 2-symbol TM that halts iff ZF (Tarski S2 + EXT/REP/POW/UNI/INF,
no regularity/choice, same `prov` as zf2.nql up to the B6a change below) is inconsistent, built from
Wade's IP/decision-DAG control (reused verbatim where possible) plus a NEW data layer: wffs are token
strings on the tape (prefix/Polish order), no Cantor pairing, no unary registers.

## 0. Why

In Wade's 393: 69 framework, ~175 DAG cells are axiom templates (1 cell/op after suffix sharing), the rest
(~150) is engine: Cantor pair/unpair/cons, copies through scratch, select/cparam, DET compare, proof parse.
SM keeps "1 cell per template op" but replaces the engine by ~10 hand-written tape primitives. Estimate
(derivation in IDEAS.md): framework ~155, DAG ~185 -> ~340. The point of the prototype is to MEASURE.

## 1. Logic (what the machine enumerates)

Tokens (prefix notation, root first):

    e x y        x e. y            =  x y        x = y
    -> A B       ( A -> B )        ~ A           -. A
    A x A        A. x A   (token `A` = forall, followed by a variable token then a wff)
    v_i          variable i (i >= 0 unbounded)

A wff is a token string generated by  W ::= e V V | = V V | -> W W | ~ W | A V W,  V ::= v_i.
Prefix-order wffs are prefix-free (no wff is a proper prefix of another) — this is what DET relies on.

Axioms (templates; p1 p2 p3 = wff params, x y z = variable params), all as in zf2.nql except B6a:

    DET  pops X = top theorem, Y = theorem below it; requires X = -> Y ps; pushes ps (see 4.DET)
    GEN  x: pushes  A x T   where T = copy of the top theorem (T is kept)
    B1  -> -> p1 p2 -> -> p2 p3 -> p1 p3
    B2  -> -> ~ p1 p1 p1
    B3  -> p1 -> ~ p1 p2
    B4  -> A x -> p1 p2 -> A x p1 A x p2
    B6a (distinctor form, NO side condition):
         -> ~ A z = z x -> ~ A z = z y  /\ ( -> = x y A z = x y ) ( -> e x y A z e x y )
         where /\ P Q abbreviates ~ -> P ~ Q.  Sound for every choice of x y z (if z is x or y the
         antecedent ~ A z = z z is refutable); the side-conditioned instances follow by two DETs since
         ZF proves ~ A z = z x.
    B6b -> A x A y p1 A y A x p1
    B6c -> E x A x p1 p1            (E x P abbreviates ~ A x ~ P)
    B7  E x = x y
    B8a -> = x y -> = x z = y z
    B8b -> = x y -> e x z e y z
    B8c -> = x y -> e z x e z y
    EXT -> A v2 <-> e v2 v0 e v2 v1 = v0 v1          (<-> P Q abbreviates /\ -> P Q -> Q P)
    REP -> A v3 E v1 A v2 -> A v1 p1 = v2 v1  E v1 A v2 <-> e v2 v1 E v3 /\ e v3 v0 A v1 p1
    POW E v1 A v2 -> A v3 -> e v3 v2 e v3 v0 e v2 v1
    UNI E v1 A v2 -> E v3 /\ e v2 v3 e v3 v0 e v2 v1
    INF E v1 /\ e v0 v1 A v0 -> e v0 v1 E v2 /\ e v2 v1 A v1 <-> e v1 v2 = v1 v0
    CHECK: halts iff the top theorem is exactly  e v0 v0  (canonical contradiction, 3 tokens).

(The implementer may transcribe EXT/REP/POW/UNI/INF directly from zf2.py's postfix op lists: postfix
"a b wim" = prefix "-> a b", "a wn" = "~ a", "x a wal" = "A x a", "x y wel" = "e x y", "x y weq" = "= x y",
wex = ~ A x ~, wa = ~ -> P ~ Q.)

Proof candidate = a bit string N (enumerated as a binary counter, see 5). It is consumed left to right as:
repeat { axiom code (prefix code over the 20 codes); then that axiom's params in order; }
until N is exhausted (END). A wff param is read as a token stream with the prefix code

    e=00  ==01  ->=10  ~=110  A=1110  v=1111 then unary 1^i 0 for v_i

and is complete when the pending-operand counter hits 0 (self-delimiting; no END token). A variable param
is read as unary 1^i 0 directly. The theorem stack persists across candidates (only theorems are on it).
Invalid DET (top is not -> Y ps) removes nothing but is a no-op; mismatching DET erases X and keeps Y.
Garbage cannot arise: every param is well-formed by construction, templates are well-formed with well-formed
params, DET output ps is well-formed by prefix-freeness. Soundness invariant: every stack entry is a theorem.

## 2. Tape layout

Orientation: the data region D must have its FREE end away from the IP. Written left-to-right here with the
free end on the RIGHT for readability; the implementer mirrors it (free end on the left of the IP marker,
N on the right) so that the IP gap grows (see 5). Runs = maximal blocks of 1s.

    ... 0^g [D] ...   with   D = A 00 B,   A = T_1 T_2 ... T_m  (theorem stack, T_m = top),
                              B = P_1 ... P_k W  c          (params, work wff, counter)

Every wff = separator run followed by tokens, tokens separated by single 0s:
    theorem separator = run of 1 one ("1"),  param separator = run of 2 ones ("11"),
    token values: e=3 ==4 ->=5 ~=6 A=7 v_i=8+i  (a token of value v is the run 1^v).
    The counter c = run 1^(c'+3) is always the LAST run of D (c' = pending operands - 1).
    A and B are separated by exactly "00" (the head/boundary); when A is empty the boundary merges with the
    gap. Inside A and B all separations are single 0s EXCEPT zeros left behind by DET erasures (allowed:
    every scan skips 0-runs; the boundary is identified as the first 00 scanning from the fixed end).

Invariant between ops: B's wffs are all params (11-separators) followed by at most one theorem-separated W,
then c. The head is at rest (A ends with T_m, B starts with P_1 or W or c).

## 3. Primitives (leaves of the decision DAG)

Each primitive is entered from a DAG leaf exactly like Wade's register ops (head on the first chain-one cell,
chain ones 1^j already written by previous trips for multi-trip ops), does its work in D, returns to the IP
region and performs "advance" (6.break.0) or the zero branch (6.break.1) as in Wade's framework.

    RB            read next proof bit: branch 0/1 (two outcomes = the decnz-style branch). On END: framework
                  does: increment N, erase B (keep c, reset c'=0), reset IP to [], restart main (no DAG branch).
    PUSH v        append token 1^v to the last wff of B (before c). Chain of 9 states for v in 3..11 (e = ~ A v0..v3).
    APP1          append one more 1 to the last token of B's last wff (unary variable index).
    NEWP / NEWT   append a new wff with param/theorem separator before c.
    INCC / DECC   c' += 1 / c' -= 1 with zero branch (Wade decnz semantics on c').
    DUP k (k=1..3) copy P_k to the end (append before c, as a token sequence, keeping P_k). Chain of 3.
    DUPT          copy T_m to the end (keeping T_m).
    DET           see 4.
    COMMIT        erase all params of B, then W becomes T_{m+1} (W crosses the boundary into A).
    CHECK         if T_m is exactly "1 0 111 0 1^8 0 1^8" halt; else no-op (non-destructive).

## 4. Primitive semantics on the tape (recommended implementations)

Head moves (not leaves themselves): 
  STEP-R: move B's first wff across the boundary into A unit by unit (take B's first 1, write 0; write 1 in
          the cell right after A's last 1 + 1... i.e. after the boundary's first zero), preserving run structure
          by carrying a "unit ended its run" flag (right neighbour 0) and leaving a 0 before the next run. Stops
          after the wff's last token (next run is a separator, or is c = the run followed by 00).
  STEP-L: symmetric (A's top wff into B). Peek the separator first (scan left over tokens >=3 ones).
  DUPX  : STEP-R of B's first wff, and for each unit also append it before c (2 writes per unit).
DUP k = (k-1) STEP-R trips, then DUPX, then rewind: STEP-L while A's top wff is a param (11-separator).
DUPT = STEP-L (T_m into B) then DUPX (rewind stops at once because T_m has a 1-separator).
DET  = STEP-L (X), STEP-L (Y): B = Y X P.. ; if X's first token is not 1^5 (->): STEP-R twice, done (no-op).
       Erase X's "->". Loop: move Y's next unit across (into A) and erase X's next unit; both must end their
       runs simultaneously, else MISMATCH. When Y is exhausted (its next run is X's separator) and X's current
       token just ended: MATCH: erase A's top wff (Y), then STEP-R (X-rest = ps into A).
       MISMATCH: erase the rest of X including its separator; finish moving Y across. 
COMMIT = erase B's leading 11-separated wffs (write zeros up to W's 1-separator), STEP-R.
CHECK  = walk T_m from its separator: runs must be 1,3,8,8 followed by the boundary; halt on success.

## 5. N (proof candidate) and the IP side

Reuse Wade's IP mechanism (marker 1, P bits, chain ones, 4.dispatch zero-counting with cap = longest car
run, 5.root, 6.break.k, 6.continue.k, 2.ret). N sits on the side of the IP opposite to D:

    [D free<-fixed] 0^10 1 P 1^j 0^g [N remaining] 000 111 [N placed] 0^inf   (mirrored: D on the left)

Digits are 3 cells "1 b 0" (b = bit), sentinel 111. RB: find the first 1 right of the gap: if it starts
"111" -> END; else read b, erase the digit, write "1 b 0" after the placed block (first 000 after 111),
branch on b. A full read rotates N unchanged through the sentinel and grows the gap g by 3|N| per candidate
(this is the IP-space drift; verify by simulation that g >= depth + chain + 3 always holds, starting from
boot's gap). END: increment N (placed block, LSD adjacent to 111, carry rightwards, overflow appends 110),
move 111 to the right of the block, erase B, reset c, clear P (IP := []), go to 5.root.

Boot: write "111" (empty N), the IP marker, gap g0 (>= 20; measure), D = "00" boundary + c = 111.

## 6. Deliverables / measurement protocol

B1 (sm_dag.py): abstract SM simulator (list-of-token strings), the program as nested lists in TMBuilder style,
hash-consing to cons cells, cell count; planted-proof test: a hand-written short derivation (e.g. B2+DET
sequence or any 3-step derivation) encoded as N bits must execute correctly on the abstract machine; the
exhaustive enumeration of all N up to ~12 bits must never halt (sanity).
B2 (sm_fw.tm fragments): each primitive as TM states on the exact layout, unit-tested on random tape snippets
against the abstract semantics (hundreds of cases), state count per primitive.
B3 (sm.tm): integrate with the IP mechanism (copy the needed states from Wade's framework text in
ext/turing_machine_explorer/TMBuilder.py; do not modify ext/), produce `#! start` .tm, crosscheck against B1
op by op (like zf/tools/crosscheck.py), run the planted proof, report total states.
