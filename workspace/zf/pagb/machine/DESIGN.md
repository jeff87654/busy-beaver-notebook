# pagb machine: a 2-symbol blank-tape TM that halts iff PA ⊢ GC (design A(a))

Goal: a TM that halts iff `PAeq ⊢TC GC_form` ⇔ `PAeq + NG ⊢TC ⊥` (`../coq/Spec.v`). It is a
proof-search enumerator over a calculus whose theorems are the PA-theorems plus the extra axiom NG.
It halts when it derives `F`.

It is the zfc_254 / m254 program (`../../m254/logic`, frozen) with `axioms()` replaced and the gate
replaced by an occurs check on term codes. The RM helpers, MP/DROP/NIP, dispatch, dual-Cantor coding, GEN and
self-freshness are unchanged. Compiled by Wade's TMBuilder (the 281-state route).

**Status: candidate, NOT frozen** (awaiting pagb-coq's SIGNED OFF line in `../INTERFACE.md`).
**449 states.** Files are LF-only and the rebuild is deterministic:
`sha256(pa_wade.tm) = ed795af79b6752d72c037d7e32eca1d23efaa6a6c0f0d07fc7ba89869f2616a6`,
`sha256(source_pa.py) = 152d4a5f82be2f12c3823478a911c5f71fd21f78a21bca06f690030582b42587`,
`sha256(design_choice_A.json) = da10ced32774ea0ea3ea91f1d84d3fe15ef17324e760579165586b431fd7abf9`.
Generated by `python design.py` from `search_a.py` (`vac='a'`, `ngform='literal'`, Q labels unpinned) and
`design_choice_A.json`.

Chosen design: A(a): functional terms, Eq-atoms only, general atom vacuity (pprov B6a) behind an
occurs-check gate, literal NGw. The interface with pagb-coq (its Coq `thm` follows `search_a.py`
exactly) is in `../INTERFACE.md`.

### History (why the earlier candidates were withdrawn)
* **FLAT 345**: one-deep relational terms with a vacuity schema `φ→∀c φ`. That schema gives vacuity
  only for the single label `c = code(φ)`. B6a needs `A→∀x A` for every `x ∉ A`, so the machine was
  incomplete.
* **A with the third variable pinned to c+1 (391–404)**: ternary vacuity was only available with
  third variable = x+1. Recovering the general case needs ∃-elimination, which needs vacuity of the
  same atom at another variable: an infinite regress, so incomplete (found by the lead; pagb-coq agreed).
* **Nested terms without a var constructor**: unsound, because a bare `v_i` collides with ⊤/F/zero.
* **A(b), unpinned flat vacuity with a 4th parameter register (429–432)**: complete only for flat formulas.
  The NG hypothesis then has to be flat as well (converting the nested NGw needs nested B6a). A flat NG
  costs ≈464, more than A(a), so A(a) wins under pagb-coq's rule.

## 0. Coding

Dual Cantor `P(a,b) = tri(a+b)+b`; codes `4·P(x,y)+tag`.

| code | term `T(n)` | formula `D(n)` |
|---|---|---|
| `0` | `zero` | `⊤` (= `Imp(0,0)`) |
| `4P(x,y)+0` | `σT(x)` (canonical `y = 1`; `σ0 = 8`) | `D x → D y` |
| `4P(x,y)+1` | `T(x) ⊕ T(y)` | `σT(x) == T(y)` |
| `4P(x,y)+2` | `T(x) ⊗ T(y)` | `∀v_x D y` |
| `4P(x,y)+3` | `v_x` (canonical `y = 0`; `Var(i) = 4·tri(i)+3`) | `T(x) == T(y)` |

* **F = code 1 = `σ0 == 0`**, closed and refutable in pprov. `¬A = A→F`, `A∧B = ¬(A→¬B)`,
  `∃x A = ¬∀x¬A`, `A∨B = ¬A→B`. Every decoded formula is a pprov formula over Eq-atoms; the Rel tag
  is used only by F.
* **Self-freshness:** every variable index in `D(n)`/`T(n)` is `< n` (n ≥ 1), so `c` is fresh for
  `φ = D(c)` and `c+1` is fresh for `T(c)`.
* The decoder is non-injective only on junk `y` (σ, var) and on the τ-collapse `Imp(0,0) = 0` (in the
  L and QI rows only, as in m254). τ uses the canonical codes.

## 1. The AX command and its roots

The command is `AX(c; x, y, u)`: `a = param1 = d + x`, `b = param2 = h + y`, `u` = literal (L's 4th
formula), `c = selector − 3`. `v_x` = `Var(x)`. A bare `a/b/c` in a term position is an arbitrary term
code. The stack order comes from the search (`search_a.py`; soundness-neutral); `python decode_pa.py`
prints the roots from the compiled source.

| row | decoded formula | pprov |
|---|---|---|
| GEN | `∀v_a h` | GEN (generalization of the cache) |
| L | `((C→U)→A) → ((A→C)→(B→C))` | B1–B3 via condensed detachment |
| QI | `∀v_a(B→C) → (∀v_a B → ∀v_a C)` | B4 (literal) |
| COMM | `∀v_a∀v_b C → ∀v_b∀v_a C` | B6b (literal) |
| B6c | `∃v_a∀v_a B → B` | B6c (literal) |
| Euclid | `T(c)==T(a) → (T(c)==T(b) → T(a)==T(b))` | E8 (literal) |
| Cσ, C⊕1, C⊕2, C⊗1, C⊗2 | `T(a)==T(b) → σT(a)==σT(b)`, `a==b → a⊕c==b⊕c`, `a==b → c⊕a==c⊕b`, ⊗ alike | ES, EPl, EPr, EMl, EMr (literal) |
| ρ1 | `∃v_a (v_a == v_b)` | B7 for a variable term (literal) |
| EX | `∃v_{c+1} (v_{c+1} == T(c))` | B7 with x = c+1 ∉ vars T(c) (literal at that x) |
| zero_succ | `0 == σv_x → F` | AZS |
| succ_inj | `σv_x == σv_y → v_x == v_y` | ASI |
| add_zero | `0 ⊕ v_x == v_x` | AA0 |
| add_rec | `σv_x ⊕ v_y == σ(v_x ⊕ v_y)` | AAS |
| mult_zero | `0 ⊗ v_x == 0` | AM0 |
| mult_rec | `σv_x ⊗ v_y == v_y ⊕ v_x ⊗ v_y` | AMS |
| NG | τ(NGw), §3 | HYP |

The Q rows are open with distinct labels x ≠ y. In the chosen point they are **not pinned**, but each one
reaches pprov's literal instance QZS…QMS (over v0, v1) through free parameters. The Q rows are ungated,
so any parameter values are allowed: zero_succ (x = a) at a = 0; succ_inj, add_rec, mult_rec (x = a, y = b) at
a = 0, b = 1; add_zero (x = c) at c = 0; mult_zero (x = a) at a = 0. The unused second labels (d, 0) of the
one-variable rows don't occur in the formula. Pinning them costs +6 (455) and buys nothing.

**AX push order** (bottom to top; `runs/push_order.txt`, from `design_choice_A.json` rorder
[15,13,2,10,18,17,6,7,8,3,14,0,11,1,9,4,5,16,12], border [0,1]):
slot 0 t (old current) · 1 GEN `∀v_a h` · 2 add_rec(a,b) · 3 succ_inj(a,b) · 4 B6c · 5 C⊗1 · 6 NG ·
7 mult_rec(a,b) · 8 EX · 9 Cσ · 10 C⊕1 · 11 COMM · 12 add_zero(x=c) · 13 L · 14 C⊗2 · 15 Euclid ·
16 C⊕2 · 17 QI · 18 ρ1 · 19 mult_zero(x=a) · 20 zero_succ(x=a) · current = gated `IND ∧ VAC`.
The read order of the command is unchanged: `AX(c; x, y, u)`, with x into param1, y into param2 after GEN,
and u (L's literal) in L's position. NSLOTS = 21.

## 2. The gated bundle

Emitted iff `c ∉ vars T(a) ∪ vars T(b)` (else current := ⊤); `φ = D(c)`:

```
IND(a,c,φ) = ∀v_a(v_a==0 → φ) → ( ∀v_a( φ → ∀v_c( v_c==σv_a → ∀v_a(v_a==v_c → φ) ) ) → ∀v_a φ )
GV         = T(a)==T(b) → ∀v_c T(a)==T(b)
```

* GV is pprov **B6a literally**, for every pair of terms t = T(a), s = T(b) and every z = c ∉ vars t ∪ vars s.
  This is exactly the gate condition. No flattening, no renaming, no pinned variables.
* IND is pprov `IND x c a` with x = a: `c ∉ φ` by self-freshness. **The machine emits IND with no c ≠ a
  guard:** the only gate is the occurs check, and with a := τ-code `c` it can be open with c = a.
  IND needs no gate. If `a` occurs in
  φ then `a < c`; if `a ∉ φ`, `IND(c,c,φ)` is valid anyway (fuzz: 400 instances with c = a, 0 false).
  The gate closes the whole bundle, which is harmless.
* **The gate** (`pagen.OCC_SRC`, `occgate`) walks the term codes a and b with a dual-Cantor work list
  (param1), items `x+1`. For each item: `x = 0` (zero) is skipped; otherwise `x = 4q+t` by repeated
  decrement, `(j,k) = unP(q)`; t = 0 pushes j (σ; junk k dropped), t = 1, 2 push j and k, and t = 3
  (var `v_j`) zeroes topwff if `j = c`. It ends with param1..3 and scratch1..2 at 0, and wffstack,
  prooflist, nextproof untouched. Spec: `spec_pa.tvars` / `gate_open`. The program layer (L2) needs one
  loop lemma for it (well-founded on the work list).
* Runtime: the walk is linear in the **value** of a and b (mod 4 by repeated decrement). Every
  register-machine operation is value-linear, so this changes nothing about halting. But simulating AX
  on huge cache/parameter values (e.g. START from an arbitrary retained state) is infeasible in rmsim,
  so the simulated checks keep a, b ≲ 3·10⁶ for the gate walk.

## 3. NG (closed) = τ(NGw), literally

`NGw = Wn GCw`, `GCw = tr (fun _ => TV 1) GC_form` (`../coq/PA_Sound.v`). It is not transcribed by
hand: `runs/GCw_coq_print.txt` is coqc's `vm_compute` of pagb-coq's `tr` (definitions copied
verbatim; nothing was written to `../coq`). `ngw.py` parses it into the machine row. Reading
(binders 10, 8, 6, 4, 2):
`¬∀n( (∃k n=k+k ∧ ∃z n=SSSS0+z) → ∃p∃q( (Pr p ∧ Pr q) ∧ p+q = n ) )`,
`Pr t := ∃z t=SS0+z ∧ ∀a∀b( t = a·b → (¬ a=S0 → b=S0) )`.

So the HYP leaf is exactly pprov's hypothesis. Measured alternatives: an α-variant with binders 0..4
(≈ −5 states, needs α-renaming), and an arithmetic re-encoding (`y≠y·y` primes, ≈ −13 states,
needs 500–800 lines of PA-internal lemmas per pagb-coq). Both were rejected by pagb-coq's 15-state rule.

## 4. Gate and collisions (`collide_a.py`, `runs/collide_a.txt`)

The gate depends on the *terms* T(a), T(b), not on label equalities. So the table enumerates all
realizable partitions of the labels `{a, b, c, u, c+1, 0}` (114 partitions, gate evaluated on realized values). For each it computes the
gate on the realized values (`spec_pa.gate_open`) and fuzzes the open instances: **0 FALSE**. Separately,
`fuzz_a.py` draws a, b as genuine term codes, some containing `v_c` (gate closed) and some not.

| situation (gate open) | effect | why pprov-valid |
|---|---|---|
| c = a (as a label) | IND(c, c, φ); GV with c ∉ vars T(a) | IND valid without a gate (above); GV is B6a |
| a = b | GV = `t==t → ∀v_c t==t` | B6a instance |
| c = 0 | φ = ⊤ (IND trivial); GV binds v_0 ∉ vars | trivial / B6a |
| u anything | u only feeds L (formula position) | L is propositional |
| c ∈ vars T(a) ∪ vars T(b) | gate closed, current = ⊤ | — |

The gate is necessary: with `T(a) = v_c` and the gate ignored, GV is false in ℕ in 200/200 fuzz samples.

## 6. Completeness checklist, mapped to pprov (`../coq/PALogic.v`)

τ maps named wffs to canonical codes, with `Wn a ↦ wim(τa, 1)`. Fw = ¬(0=0) gives code 1 by one MP
with `0=0`; pagb-coq decodes code 1 as σ0==0. The halting suffix follows. Every pprov constructor
except B1–B3 (L by CD, as in m254) is a **literal** machine root:

| pprov | machine source | how |
|---|---|---|
| HYP NGw | NG row = τ(NGw) | literal (parsed from coqc output) |
| DET | MP command (macro `mp`) | — |
| GEN x a | GEN slot `∀v_a h`, any variable | literal (macro `gen`) |
| B1, B2, B3 | L (B2 = Peirce with F; B3 via ex falso F→b from K + B6c) | derived by CD, as m254 CD254.v |
| B4, B6b, B6c | QI, COMM, B6c | literal |
| **B6a z t s** (z ∉ t, s; any terms) | GV with a := τ(t), b := τ(s), c := z (gate open exactly when z ∉ vars t ∪ vars s) | **literal** |
| B7 x t (x ∉ t) | t a variable: ρ1 (any x). Else EX gives x₀ = τ(t)+1, then α-rename ∃x₀ → ∃x using B6a (literal, any variable), E8 and ρ1 | literal / derived without circularity (B6a is primitive) |
| E8, ES, EPl, EPr, EMl, EMr | Euclid, Cσ, C⊕1, C⊕2, C⊗1, C⊗2 | literal |
| AZS, ASI, AA0, AAS, AM0, AMS | the six Q rows | literal: the instances at a = 0, b = 1 (or c = 0) are exactly QZS…QMS (§1) |
| AIND x c' a | bundle IND(a, c, φ): a := x, c := τ(φ), b := 0 (zero, no vars); the gate needs c ∉ vars T(x) (true when c > x, padding φ if needed); α-rename c → c' via B6a / B4 / B6c | literal when c' = τ(φ) |

There are no derived vacuity lemmas at all. Every B6a instance pagb-coq's completeness needs is a
leaf of the machine.
