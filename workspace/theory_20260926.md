No nontrivial new champion was established by this investigation.

## Exact configuration encoding

Our implementation of the page's displayed B(a; vector) configuration places the head in A, reading a blank immediately right of this finite word:

    '111' + ''.join('01'*(3*v+1)+'1' for v in vector[::-1])
          + '1' + '01'*(3*a+1) + '0011100'

All cells outside the word are zero. With this encoding, the macro rules checked on finite examples are:

- B(a; b+1, tail) -> B(2a+4; b, tail).
- B(a; 0^k, 0, n+1, tail) -> B(0; 0^k, a+2, n, tail).
- B(a; 0^k) halts.

These are terminating ordinal-style recurrences; a finite simulation prefix landing in B is useful only when subsequent machine behavior still implements the recurrence. Reaching B after permanently changing core transitions alone is not a halting proof.

## Source details that require correction or a clarified convention

Independent direct simulation of the exact table above gives these blank-tape snapshots:

| Steps | Configuration |
| --- | --- |
| 2154 | B(0; [0]*11 + [2]) |
| 7984 | B(0; [2] + [1]*11) |
| 8574 | B(4; [1]*12) |

The source's stated B(2; [1]*12) at step 8178 does not match its literal configuration definition. At step 8178 our head is in A, on blank tape, but the group lengths between separators are [4]*12 + [6,1], so the tape is not in the B form.

The listed halting sigma formula also differs by one under the explicit 1RZ halt convention. Small exact examples:

| Input | Steps to halt | Ones at halt |
| --- | ---: | ---: |
| B(0; []) | 29 | 10 |
| B(0; [0]) | 58 | 12 |
| B(1; []) | 35 | 13 |
| B(1; [0]) | 88 | 15 |
| B(2; [0,0]) | 195 | 20 |

These support sigma = 3*a + 2*k + 10, whereas the source has +9. Excluding the final write would explain the sigma discrepancy. Neither discrepancy invalidates the published conservative lower bound; the verified starting accumulator is larger. These observations are reproducible, not a claim that the source author has confirmed a correction.

## One-step initializer search

Enumerated all 28 choices for a fresh initial state H: write 0 or 1, move L or R, enter any core state A through G. H is never entered again. Each was directly simulated for up to 300,000 steps, recognizing B forms on visits to A.

No larger seed was found. A blank-preserving transition into A is the ordinary one-step delay. H0 = 1RB exactly duplicates the original first step. The strongest different recognized seed was H0 = 1LA, which reaches B(0; [0]*6 + [2]) after 1321 total steps, substantially below the original twelve-level configuration. H0 = 1LD reaches B(0; [2]) and halts after 3973 total steps.

Results for seeds that did not reach B are bounded observations, not nonhalting proofs.

## Initialization-sensitive transition contexts

For a copied-state insertion, instrumented each incoming core transition together with the symbol seen immediately afterwards. Across 240 finite B derivations covering a=0..3, zero-prefix lengths 0..4, n=0..2, and four tail patterns, only these contexts occurred during blank initialization but not in the sampled recurrence derivations:

- C0 followed by a read of 0 in D.
- E1 followed by a read of 0 in C.

This suggests testing C0 -> 1RH with H1 = 1LE and arbitrary H0, or E1 -> 0LH with H1 = 0LB and arbitrary H0. Absence from finite samples is not a proof of the general invariant. The collaborating search agent's exhaustive single-split search did not find an improved recognized seed.
