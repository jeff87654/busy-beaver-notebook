1. Configurations
-----------------
Read the tape in 2-cell blocks aligned with the head.  A K-configuration is
    0^inf  S_1 11 S_2 11 ... 11 S_(k-1) 11 (01)^x (10)^y   A> 01  0^inf,        S_i = (01)^p_i (10)^q_i.
The last segment (x, y) is the accumulator.  In Coq: K x y U, U = [S_(k-1); ...; S_1] (nearest first).
The blank tape reaches K-config (5,1)(1,1)(1,1) after 520 steps.

2. K-level rules (each proved in Coq for all parameter values; also grid-checked on literal runs, rulecheck.py)
--------------------------------------------------------------------------------------------------------------
  R1   (x+2, y)                  -> (x, y+4)
  R2   (p, q+2)(1,1)^j (1, y)     -> (p, q)(y+4, 1)(1,1)^j                          (x = 1, donor q >= 3)
  R3   (p+2, 1)(1,1)^j (1, y)     -> (p, y+4)(1,1)^(j+1)                            (x = 1, donor (p>=3, 1))
  R4   (1,1)^j (1, 2m+1), blank to the left  -> (0,1)(1,1)^(j+m+1)(0,3)            (exhaustion + rebuild)
  R6a  (p, q+2)(1,1)^(j+1)(0, y)  -> (p, q)(y+2, 1)(1,1)^j (0,3)                    (x = 0)
  R6b  (p, q+2)(0, y)             -> (p, q)(y+1, 3)
  R7   (p+2, 1)(1,1)^j (0, y)     -> (p, y+2)(1,1)^j (0,3)                          (middle p+2 >= 3, or leftmost p+2 even >= 2)
  R8a  (0,1)(1,1)^(j+1)(0, y)     -> (y+3, 1)(1,1)^j (0,3)                          (leftmost (0,1))
  R8b  (0,1)(0, y)                -> (y+2, 3)
The borrow always takes the rightmost segment that is not (1,1); (1,1)-segments act as zero digits.

3. Invariant (Valid x y U) and why the halt is never reached
-------------------------------------------------------------
  phase O: every p, q and x, y odd.
  phase E: k >= 2, x even, y odd, leftmost segment (even, odd), all other segments (odd, odd).
Case analysis (step_valid): phase O, x >= 3 -> R1; x = 1 -> R2 / R3 on the rightmost non-(1,1) segment (odd, odd, not
(1,1), so q >= 3 or (q = 1, p >= 3)), or R4 if all digits are (1,1) (y odd).  Phase E, x >= 2 -> R1; x = 0 -> R6a/R6b/R7
on the rightmost middle non-(1,1) segment, else on the leftmost (even, odd) segment: R6a/R6b (o >= 3), R7 (e >= 2, o = 1),
R8a/R8b (e = 0, o = 1).  Every result is again Valid (R4 and R8a/R7/R6 keep phase E; R8b returns to phase O).
The rules themselves hold for all parities; parity is needed only to exclude the configurations no rule covers (x = 1
with leftmost (0,1); x = 0 with leftmost (1,1) or a donor with q = 0; exhaustion with even y).  Random segment configs
with arbitrary parities DO halt (299 of 3000 in a 2e6-step test), so the invariant is essential.
Empirically: 12000 K-steps from 400 random Valid configs, all Valid, 0 halts (valid.py).
