METHOD (tools in this folder; everything at Idle priority, at most 2 cores; PIDs in pids.txt)
  S1 reb7.py (per machine, resumable jsonl):
    fit7.py: rules fitted from literal probes (rk7.exe); nothing taken from dlscan2 params:
      D (a,b)->(a-1,F0 b); R2 last digit -1, a:=A2(b), b:=B2(b); borrows over k=1..7 zeros with the REAL tails
      (entries affine in b, refill x(b,k)), extrapolated by a tail pattern pre/[x]/head/mid*/end (checked up to k=12 on
      random configs); small-b behaviour of every borrow recorded (thresholds, halts).
      Template variants: dlscan prefix absorbed into digits; recodings s=u^j s2, S=u^j S2 (this fixed the F1 machine r).
      Marker prefixes (568 rows with P=1 etc.): marker_scan of K(0^n;0;b) finds the TRUE exhaustion level nE (levels
      n>nE are marker borrows that shrink the list: a staircase W_n..W_(nE+1)); marker borrows fitted like borrows.
      Exhaustion map per residue class of b (b=60..107, re-checked at 300..347): HALT / rebuilt list pre+mid^cnt+suf
      with counts affine in t=(b-c)/p / other; also probed from the natural predecessor K(0^n;1;b) (composite) when
      K(0^n;0;b) is not a natural K-moment; disagreements flagged.
      Checks: lockstep against the literal blank-tape trace (3e8 steps / 3000 K-configs), 80 random literal configs
      (60% forced borrows with k<=12, marker borrows).
    eng7.py: residue engine for the fitted rules. Levels U_j (borrow over j-1 zeros) and W_i (marker borrows) as tables
      mod Q (Q1=80640, Q2=483840), exact integers below 1e15, eventual periodicity in the level index by EXACT state
      recurrence, modulus tracking (a value known only mod a divisor of Q when a cycle length does not divide Q),
      staircases with CRT candidates. rounds7.py: exhaustion rounds from the last literal K-config (exhaustions with an
      exact accumulator <= 3000 are run literally), class branching when a residue does not determine the class
      (Y1-type situations would show up as CLASS-DEPENDENT; none occurred). Linear invariant search (a, b, sum ds,
      len ds mod 2,3,4,6) including the rebuild map.
  S2 mrounds.py: exhaustions that leave the template: ffree.exe (free-prefix follower) finds the prefix P2 of the next
    K-moment; template T2 = T with P = P2 gets its own rules/engine/exhaustion map; cross maps T->T2 per class
    (xprobe.exe), n-affine maps for huge list lengths; states (template, V mod Q, n) explored; loop = repeated state
    (or repeated (template, V) with an n-independent step).
  S3 template-free growth for rows the fitter cannot model (NOFIT/NO-K): literal K-trace in the dlscan template and
    blk.exe (longest periodic block and span after 3e6/3e7/3e8 steps). Bimodal: <= 100 cells (counters, odometers,
    additive engines; dlscan R1 slope 0 or R2 a=b+1) -> NOT-RECORD-CLASS(LOW-GROWTH); 16000-28000 cells (like the
    champion) -> S4.
  S4 two Opus subagents (counters/, grows/) for families my tools could not model: outer-counter families (a prefix of
    size ~b or ~n created at the exhaustion) and growing NOFIT rows (absorb rules, segment codings, +1-per-exhaustion
    growers). Abstract maps validated against literal runs (100-400 random configs each + blank-tape traces).
  Far-window literal check (echeck.py): one representative per NEVER family (77); exhaustion probed literally at the
    visited classes near b=1000 and b=4000 against the fitted class rule: 75 OK; 2 probe-budget timeouts at b=4000
    (expected lists of 6001-24001 digits), both OK at b=1000.

LIMITATIONS
  Rules are fitted and checked on literal probes (lockstep, random configs, far windows), not proved. The residue engine
  is exact given the rules; in the huge phase it assumes b >> k at every borrow (thresholds are linear in k, b is a
  tower). Class maps are assumed to persist beyond b ~ 1000 (checked to 4000 where the budget allowed). LOW-GROWTH is
  literal evidence (bounded accumulators after 3e8 steps), not a proof that no late f_omega phase exists. (The N2 family,
  earlier only "no halting configuration found", is now Coq-proved non-halting.)
