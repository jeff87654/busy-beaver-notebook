    (S) Safety: every event at depth j has A >= 2j.  This is a paper proof.
        Lemma F: start from [2 | 2^(j-1), y, REST] with y >= 2 even at position j.  Every event while positions 1..j are
        emptied has A >= 2*depth.  REST is untouched.  Positions 1..j empty with A = F_j(y) >= 2y + 4j - 2.  The proof is
        by induction on j: a_0 = F_{j-1}(2) >= 4j-2 and a_{t+1} = F_{j-1}(a_t + 6 - 2j) >= 2 a_t + 6.
        Any event E at depth j: let E* be the last earlier event of depth >= j.  After E* the prefix is [2 | 2^(j-1), y]
        with y = 2, or y = A(E*)+4-2j >= 4.  So A(E) = F_j(y) >= 4j+2.
