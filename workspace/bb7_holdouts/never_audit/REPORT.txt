METHOD (independent of reb7's code; reused only the simulators: symsim.cpp from bb8_resid with a --stopq patch)
  1 Coding, found from literal tapes (lit.exe ends/kv), compared with reb7 only afterwards: tape -> v-list (1-runs
    separated by single 0s, oriented so the K-event head is on the right).  Digit codings: V (1^d 0), U10 ((10)^d,
    separator 0 or 00), U110 ((110)^d), C1 (champion).  K-config = [d_1..d_n, A] + fixed tail TF at a (state, end)
    event with z zeros before the head.  detect2() picks (event, coding, TF, z) by the fraction of literal K-pairs that
    are plain decrements.  This independently reproduces reb7's templates (up to coding offsets) for all fitted rows.
  2 Rules MEASURED by sound symbolic execution: K-configs with symbolic digits/A (symbol = r mod 720, >= 1000) run in
    symsim to the next K-moment: D_k: [.., y+c, 0^k, A] -> [.., y, R_k(A), tail, A'] for k = 0..12, 20, 30 (deep) /
    0..6, 12, 20 (broad), then re-checked on 72-216 probes per row (left contexts [], [3], [X], small y, A classes).
    Where a proved acceleration rule skipped a K-moment, the probe was re-measured by exact runs at A ~ 1200-1920 with an
    affine fit per symbol and a 3rd verification point (marked exact_fallback).  0 mismatches on every CONFIRMED row.
  3 Exhaustion: [X] + TF with X symbolic in each class r mod 720 (r < 48 deep, r < 24 broad, all 720 for the 6
    largest rows): HALT / rebuilt K-config (shown symbolically, e.g. [4, 2^(X/2-1)]) / leaves template.  Sound for
    every X >= 1000 in the class.  In the 6 largest rows the halting set over all 720 classes is exactly "all odd
    classes" (r,s,h,u) or empty (F70, F279), so every halting condition met is a parity condition (tower-stable).
  4 Invariants: all w_D*sum(digits) + w_A*A (mod 2,3,4,6) kept by every literal K-pair AND every symbolic rule, constant
    on the literal run; then the exhaustion classes it allows, whether any halts, and whether the symbolic rebuild
    restores it.  For the dl3 F3-type rows (no linear invariant): f3check.py, projected parity P = A + c*d_last
    (c = decrement increment) with the "last multi-zero borrow" argument (below).
  5 Literal: lockstep of my rule engine against the literal blank-tape K-trace (1e9 steps deep: 17k-48k K-pairs per
    row; 1e8-2e8 broad): 0 misses on every CONFIRMED row.  Literal full exhaustions in the real class are inside these
    runs (e.g. r: X = 848 at step 281429 -> 425-digit list; F70: X = 604 at step 139013 -> 606 digits; F279: X = 850;
    i: X = 91; X33: X = 65).  Constructed literal exhaustions (F3 row n): [1,0,0,6] -> B2 -> exhaustion X = 1374 even,
    rebuilds; single-digit configs with odd projected parity halt at once (the halting class is real).
  6 Halting thresholds (thr.py, 51 deep rows): exact runs of [y, 0^k, A], k <= 8, A <= 2k+8: the only halts are borrows
    with A <= ~2k (linear threshold); the literal run's smallest A at a borrow over k zeros is far above it (e.g. F70:
    k=1 A>=4, k=2 A>=19; r: 8, 92; F86: k=3 A>=3069).  No row unsafe.

ARGUMENT FOR THE dl3 F3 ROWS (f3check.py; the generic invariant search finds nothing, my "last-borrow" route alone
  fails because D flips the parity of A): with D: A -> A+c (c = 3 or 5, odd), P = A + c*d_last mod 2 is the parity A
  will have when the last digit has run down.  Measured: D and B1 keep P; B2 sets P = 0; B_k (k >= 3) sets P = 1 but
  leaves the last three positions nonzero; nothing but a B2 decrements position n-2, so after any B_k (k >= 3) and
  after any rebuild a B2 happens before the next exhaustion.  Hence X_E = 0 mod 2, and the exhaustion halts only for
  odd X (all 48 classes measured).  Same conclusion as dl3's (their a and B1 are my P and B2).  One broad row with even
  c (1RB1RA_0LC0LF_1RD1LC_1LG1RE_1LB0RG_1LE1LF_---0RA): D keeps A mod 2, every B_k (k >= 2) leaves its last two digits
  nonzero, so the last borrow is a B1, which sets A = 3: X_E odd, halting class even: CONFIRMED.
