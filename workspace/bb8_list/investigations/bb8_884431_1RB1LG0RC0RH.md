- The task's description of the rules was slightly off. Exact rules (b = number of (11) pairs, accumulator run length 2b+1):
  R3 has refill **2(b+1-k)** (it depends on k), tail digits **2^(k-1)** (not 1^(k-1)), a = 2, b = 0.
  R4 rebuilds (4, 2^(b-1)). The probes that "never halted" in the task text were k < b; the scan's own output does show HALTs

| rule | statement |

| R1 (a >= 1) | K(ds; a; b) -> K(ds; a-1; b+1) |

Machine-level phases (planner8.py exact symbolic execution; every one is a Coq lemma, see `gen884.py`):
- `R1P` (13 literal steps + crossings): `A> 0 0 1 1 (11)^b 0 1 l -> A> 0 0 1 1 1 1 (11)^b 0 l`.
- `TR` (13): `A> 0 0 1 1 (11)^c 0 0 w -> [0 1 1 0 1] C> (11)^c 0 w` (first right sweep E, left sweep G/A, a left stack appears).
- `LOOP` (11): `[0 1 1 0 l] C> 1 1 (11)^r 0 0 w -> [0 1 1 0 1 1 0 l] C> (11)^r 0 w`: one zero of the gap moves into the stack, one (11) of b is spent.
- `FINA` (8): `[0 1 1 0 l] C> 1 1 (11)^r 0 1 w -> [0 1 1 0 l] A> 1 1 1 (11)^r 0 w` (the digit loses one 1, the run gains one).
- `FINB0` (6, k = 0) and `FINBT` (9, k = t+1): a left sweep over the stack `(011)^t`, which becomes the tail digits `(110)^t`.
- `END4` (14): all digits zero, run exhausted: `[(011)^t 0 1 1 0 1] C> 0^inf -> A> 0 0 1 1 0 (110)^t 1 1 1 1 0 0^inf`.
- Composition: R2 = TR, FINA, FINB0; R3 = TR, k x LOOP, FINA, FINBT with b = k + 1 + r, refill 2r+4; R4 = TR, b x LOOP, END4.

## Why it never halts (the invariant; same lemma skeleton as `BB8_240161_1RB0RA.v`)

- `R1iter`: K(ds; a; b) -->* K(ds; 0; B) with b + a <= B.
- `CH`: for b >= 1, K(x::U; 0; b) -->* K(0::U; 0; B) with b + x <= B (R2 gives a = 2b+2, then R1iter).
- `EX`: K(2^j ++ (w+1)::U; 2; 0) -->* K(0^(j+1) ++ U; 0; B) with B >= w + j + 2.
- `IN`: if k = j+1 < B then K(0^(j+1) ++ v::U'; 0; B) -->* K(0^(j+2) ++ U'; 0; B2) with B2 >= B + v. R3 applies since k < B, the refill is 2(B-k+1) >= 4, `EX` clears the 2-tail with b >= B+..., and induction on v continues.
- `CLR`/`GEN`: a configuration with all digits nonzero reaches the all-zero family, every reset on the way has k < b. The rebuild
  (4, 2^(b-1)) is all nonzero again, so `Top B -->+ Top B'` for every B.
- `init_reach`: 58 literal steps from the blank tape give K([4]; 2; 0), then `GEN`.
