## Verdict

**The machine never halts.** It is a tetration-rate counter built from "levels":
- In each level, one block `010` pays for one doubling of a counter n.
- At the end of a level, the counter becomes the next level's supply of blocks.
- Some level endings do halt: 8 of the 33 (prefix, A mod 11) combinations halt.
- The level residue (prefix, A mod 220) enters a 4-cycle that avoids every halting ending, from level 3 onward.

There is no sigma, and it is **not a record candidate**.

## Configuration families

Tape order, blank outside the word. `l` is the rest of the tape to the left, which the rules never visit:

```
Pc(a,n) = l (010)^a 0111 0111 1^n 01010 B>0        (head in state B on the blank right of the word)
Qc(a,n) = l (010)^a 0        1^n 01010 B>0
Yc(M)   = A>0 (01)^M                              (head in state A on the blank left of the word)
L(p,A)  = p Qc(A,3),  p = 1 or 11 (and a third prefix 111101001, never used on the actual run)
```

- General rules: k ≤ 60 and a ≤ 8, each with the blank left context and 4 random contexts.

**Mechanism of one rule**, e.g. P1:
1. **Transfer loop** (`Tloop`): `X 1^(j+3) (01)^m 0 B>` -> `X 1^j (01)^(m+3) 0 B>`. Each pass crosses the (01) run
   twice, which is why a rule costs Θ(n²) steps.
2. A few sweeps at the left boundary absorb the leftover cells and consume that rule's (010) blocks.
3. A rightward **F/B sweep** (`sw_BR_101010_111111_c01010`) carries the context `01010` to the right and turns every
   (10) pair into 11.

The result is n -> 2n + c. The (010) region is never crossed; blocks are only eaten from its right end.

## Levels

Write A = 8 + 11J + r with 0 ≤ r ≤ 10. Then L(p, A) runs as follows:
1. Q0 and then P0 give Pc(11J + r, 88).
2. J cycles of P1, P2, Q1 follow. Each cycle uses 11 blocks and maps n = 3k+4 to 8n+215 = 3(8k+81)+4.
3. After J cycles, n = N_J = 3·G(J,28)+4 = (831·8^J − 215)/7, where G(J+1,k) = G(J, 8k+81) (`level`, `cycles`).
4. The level then ends as follows:
   - if r ≤ 4, at Pc(r, N_J);
   - if r ≥ 5, P1 and P2 take it to Qc(r−5, 4N_J+90) (`level_Q`).

**Why it never halts** (`levels.py`, `levels_out.txt`; Coq `Lv_step`):
- (A−8) mod 220 fixes both r and J mod 20.
- For all J, G(J,28) mod 55 depends only on J mod 20, because x -> 8x+81 has period 20 mod 55 (`Gm_20`).
- So the next level's (prefix, (A−8) mod 220) is a function of the current one. Level 3 enters a 4-cycle:

| state | prefix | J mod 20 | r | ending | next A | G mod 55 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 1 | 15 | 6 | Qc(1,·) -> Y(n+12) | 8G+79 | 29 |
| 2 | 1 | 7 | 6 | Qc(1,·) -> Y(n+12) | 8G+79 | 44 |
| 3 | 1 | 18 | 5 | Qc(0,·) -> Y(n+5) | 8G+74 (prefix 11) | 26 |
| 4 | 11 | 4 | 10 | Qc(5,·) -> 1 Pc(1,·) -> P2 -> Qc(1,·) -> Y | 32G+343 | 43 |

Here G = G(J,28). The cycle is 1 -> 2 -> 3 -> 4 -> 1, and level 3 is state 1 (J = 943,035 ≡ 15 mod 20).
- The halting residues are r ∈ {4, 8} for prefix 1 and r ∈ {1, 2, 7, 8} for prefix 11. The cycle never hits them.
- Heuristically, each level halts with probability about 2/11 to 4/11. This machine survives because the tower
  residues lock into a non-halting cycle.
