# BB(8) holdout, subtask 048631: `1RB---_0RC1LG_1LB1RD_0RE1RA_1RF0LC_1LE1RG_0LH1RE_0RB1LG`

Source: holdout of BB(8) subtask 048631, NOBOUNDARY digit-list row of `neighbors\dl2_hits.tsv`
(template `R,E,P=1110,u=1,s=10,d=1d+0,b=1b+0,S=-`). The undefined (halting) transition is A1.

## Verdict

**The machine almost certainly never halts, but this is NOT proved: no Coq proof was written.
Confidence: strong evidence** (an exact first-return map was found and verified on millions of literal transitions;
no halt in the literal runs, see "Verification"). Not a record candidate (no halt, no sigma).

What is delivered is an exact reduction: the machine is a deterministic, total, explicit rewriting system Phi on
"standard heads" (a; t1..tk). With Phi, the non-halting proof is reduced to machine-level simulation lemmas
(the remaining gap, below). The digit-list NOBOUNDARY label is a false positive (see "Why the screen was misleading").

## Behaviour in one paragraph

The tape grows only logarithmically in time: the right end advances by 4 cells each time the step count doubles
(extension steps 632, 1644, 4002, 13238, 28078, 57998, 118332, 349732, ...; ratios about 2, and about 3 every fourth time);
10^9 literal steps reach width 90, 9*10^9 steps width 102. The run is a sequence of epochs of constant tape width. Inside an epoch the head keeps
returning to the left end (state H on cell -2, reading a blank), and each return tape is a standard head
`T(a; t1..tk) = 0^inf (10)^a 11 0^(2a+3) 1 0^(2t1-1) 1 ... 0^(2tk-1) 1 0^inf` (blocks `B(n) = 0^(2n-1) 1`; the word is
`(10)^a 11 B(a+2) B(t1)...B(tk)`). The map from one standard head to the next is an explicit total function Phi on
(a>=2; list of positive integers): a small-digit carry system with period-5 pushes (a mod 5) and a period-10 count of 1-digits.
A width extension is just Phi acting on an exhausted list. Halting needs the pattern `C> 1 1 1`; A is entered 8.5 million
times per 10^9 steps and always reads 0.

## Halting criterion (exact, from the transition table)

A is entered only from D1, D only from C1, and A1 is the only undefined entry. So the machine halts iff at some time the head
is in state C on a cell x with cells x, x+1, x+2 = 1,1,1 (C1 -> D1 -> A1); equivalently the head is in B on a 0 followed by 111.
Statistics over the first 10^9 steps: D reads 1 exactly 8,537,324 times, A is entered each time and reads 0 every time.

## Standard heads and the exact first-return map Phi

Coordinates: cell 0 is the first cell of the word; the head is in H on cell -2 (blank); cell -1 and everything left of it
is blank; right of the word everything is blank. Pair view (cells 2i, 2i+1): `[10]^a [11] [00]^(a+1) [01] ([00]^(t-1) [01])...`.
The tape width is conserved inside an epoch: 2a + sum(t) = const.

Phi (python `phi.py`, Rust `phicheck.rs`; ts = list of positive integers):

```
push(a): a mod 5 in {3,4}: (3; 2a-6)     a mod 5 in {0,2}: (2; 2a-4)     a mod 5 = 1: (2; 1, 2a-5)
a >= 4:   Phi(a; ts) = push(a) ++ ts                    (ts untouched; independent of ts)
a in {2,3}: P = maximal prefix of ts with entries in {1,2} (length m, sum s, u = 2m - s = number of 1s),
          t = next entry (>= 3) or the end of the list, tail = (t-2) :: rest   (t-2 >= 1), tail = () if the list ended
          A = a + m + 1,   E = 2a + s + 2
          u mod 10 = 0 (includes P all 2s, P = ()):  Phi = (E/2; tail)        (a pending head, pushed at the next step)
          else  A mod 5 in {3,4}: (3; E-6) ++ tail    A mod 5 in {0,2}: (2; E-4) ++ tail    A mod 5 = 1: (2; 1, E-5) ++ tail
```

Phi is total on all pairs (a >= 2; positive list) and its outputs again have a >= 2 and positive entries: E-6 >= m >= 1,
E-4 >= 2, E-5 >= 2, push values >= 2, t-2 >= 1 or dropped, E/2 >= 2. The first standard head from the blank tape is
`(3; )` at step 452 (H on cell -2, tape `00 (10)^3 11 0^9 1`); then (4;), (3;2), (5;), (2;6), (3;4), (4;2), (3;2,2), (6;),
(2;1,7), (3;1,5), ... The run is the Phi-orbit of (3;). Standard heads seen per width 18, 22, ..., 62: 1, 2, 5, 13, 21, 42, 85, ...

### History of Phi (what the checks found)
The first version of Phi had "u = 0" in place of "u mod 10 = 0" and matched 4165/4165 transitions up to 3*10^6 steps and 1500/1500 random
states. A longer literal run then found one mismatch at step 4,484,940,758 (prefix of length 24 with 10 ones, end of list): the
machine returned (23; ) instead of the push. Tabulating every (m, u) (`tabmu2.py`) showed that the class depends on u only through
"u mod 10 = 0" (pending head) and otherwise on A mod 5. All checks below use the corrected Phi.

## Structure (conjectural reading)
- Epoch = fixed total weight 2a + sum(t): the list is a stack whose bottom entry is decremented by 2 each time the stack above is exhausted
  (an all-2 prefix is absorbed into a; a >= 4 is pushed back as one number of size about 2a in one of 5 shapes by a mod 5).
- Width extension: when the list bottom is used up the pending a (a = 10 at step 59248, then a = 5 with gap 29 at step 60144) rebuilds a list with total
  weight +2 and a new epoch starts at (2;14), W 38 -> 42 (step 60444). No special case is needed in Phi.

## Why the screen was misleading
The K-shape of `neighbors\kfit.py` (head E on a blank right of all ones) occurs here only at the width-extension events (steps 6, 40, 62, 182, 204,
638, 660, 1650, ...), because the real activity is the fixed-width stack process above. The rules R1..R4 were fitted on constructed K configurations
that the machine never presents between those events, so the constants (b := 3, refill 0) carry no information about the dynamics.
Quick_Sim does not help either: block size 4 (the guessed size) proves 0 rules in 2*10^5 loops; block size 1 proves 102 plain rules and 0 general or
exponential rules in 10^6 loops; sizes 2, 3, 6, 8 prove none (`qs_n1.txt`).

## Other non-halting arguments that were tried and failed (negative results)
- Cycle / translated cycler: not applicable (width grows, no repeat).
- Two-DFA closed relation (`sat2dfa.py`, CaDiCaL via pysat): left and right DFA read toward the head, relation R subset Q x SL x SR, closure with all
  predecessor states, halting entry excluded. UNSAT for (nL,nR) = (2,2)...(6,6) [6x6: 249 s], (7,4), (8,3), (8,5); TIMEOUT 4-10 min for (4,7), (3,8), (5,8).
  The relation g = 2a+3 and the mod-5/mod-10 pushes are not regular, so a regular certificate is unlikely at any size.
- n-gram closed position set (`ngcps.py`, least fixpoint): the gram set saturates (all 2^(n+1) grams) at n = 8 and halt is reached.
- Backward reasoning from `A> 1` (`back.py`): the backward tree grows about 1.3x per 2 levels (115,583 patterns at depth 60) and does not die out.

## Remaining gap (precise) and a proof plan
Everything is reduced to proving, in busycoq (`Individual82`, `multistep_nonhalt` + `progress_nonhalt_cond`):
1. `init_reach`: c0 -->* `Cfg(3; )` (452 literal steps; `Cfg(a;ts)` = H on the blank cell -2 with `word(a,ts)` from cell 0).
2. Invariant `Inv c := exists a ts, a >= 2 /\ (all entries of ts >= 1) /\ c = Cfg a ts` and the single simulation theorem
   `forall a ts, a >= 2 -> Cfg a ts -->+ Cfg (Phi a ts)`. No inequality along the orbit is needed because Phi is total on the whole family.
3. The simulation theorem splits into machine-level lemmas (planner8 crossing lemmas + inductions):
   - a >= 4 (residues of a mod 5; ts untouched; about 11 a^2 steps): the head does repeated pair-shuffling sweeps over `[10]^a [11] [00]^(a+1)`
     (see `pushtrace.py 10 "" 0 420`); needs a nested induction on a (a = 5k + r) with an intermediate family for the half-processed region.
   - a in {2,3}, prefix P in {1,2}^m then t >= 3 or the end of the list (about 250 m steps, independent of the tail beyond t): one induction over the
     digits of P with a finite control (A mod 5, number of 1s mod 10, partial sum); the outputs are as in Phi. The only part of the tail that
     is touched is the front of B(t): t-2 means 4 cells move from B(t) to the head part. Cost for P = (): 312 steps (a=2), 570 (a=3).
   - Totality/positivity of Phi (elementary arithmetic).
4. Then `Theorem nonhalt : ~ halts tm c0.`
The scripts `pushtrace.py`, `trace3.py`, `rules2.py`, `rules_a23.py`, `tabmu2.py`, `randlist.py` show every case literally; `phi.py` is the specification.
A prover should first fix the Coq statements for the two case families (symbolic a, resp. symbolic digit list) and let the planner derive crossing lemmas.
Caveat: Phi was fitted from literal data and, as the history above shows, a regime can be missed; any new Coq lemma will validate or correct it.
