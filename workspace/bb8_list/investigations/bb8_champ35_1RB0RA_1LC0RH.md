## Configuration family and rules (all proved in Coq for all parameters)

Head in G on a blank at the right end, nothing to the right. Digits nearest-first in `ds`:

    Kc ds a b = 0^inf 1 .. (01)^(3 d_2+1) 1 (01)^(3 d_1+1) 1 (01)^(3a+1) 1 (01)^(3b+1) 1 (01)^2 G> 0^inf

| rule | statement | Coq |
| --- | --- | --- |
| R1 | Kc ds (S a) b -->+ Kc ds a (2b+2) | `R1` (ROUND^(3b+1) then `R1F`) |
| R2 | Kc (S y :: t) 0 b -->+ Kc (y :: t) (2b+2) 0 | `R2` (`ROUNDS`, `R2F`) |
| R3 | Kc (0^(M+1) ++ S y :: t) 0 b -->+ Kc (0^M ++ (2b+2) :: y :: t) 0 0 | `R3` (`ROUNDS`, `E3`, `HOPS`, `X3`) |
| R4 | Kc (0^(M+1)) 0 b -->* halted configuration (E0 undefined) | `R4` (`ROUNDS`, `E3`, `HOPS`, `X4`, `TLPS`, `FIN`) |

Machine-level phases (all generated by `gen35.py` from planner scripts; statements in `phases35.v`, crossing lemmas `cr_*`/`cx_*`):
- `ROUND`: l 1 (01)^(N+1) 1 (01)^T G> -> l 1 (01)^N 1 (01)^(T+2) G> (8 literal steps + 2 crossings); `ROUNDS` iterates it 3b+1 times, so the b-run is
  moved into the tail and doubled (this is the quadratic part: 36b^2+156b+130 literal steps for R1).
- `R1F`, `R2F`: the b-run is empty; three units of the next run are moved (a-run for R1, digit run for R2) and the tail grows by 3 units, giving 2b+2.
- `E3`, `HOP` (loop over the zero digits, one per round, in both counters m and j), `X3`: R3. The new digit 2b+2 hops left over all zero digits.
- R4: `X4` leads to a loop `TLP` over the tail units (each unit becomes two (101) blocks on the right), then `FIN` halts at E0.
Literal checks (independent of Coq): `fam.py` / `tr3.py`: R1: b=0..3 steps 130, 322, 586, 922 (= 36b^2+156b+130); R2, R3 match; halting at E0 for K(0;0;0) after 1004 steps (n = 1), 1153 (n = 2)...

## Abstract termination argument (proved, `all_halt`)

Lexicographic order on equal-length lists (most significant digit = farthest). `lex_acc` proves Acc by induction on the length and strong induction on
the leading digit; `ltds` is the order on reversed nearest-first lists. R2 and R3 decrease the list (`ltds_R2`, `ltds_R3`), R1 iterates (`R1ITER`), an
all-zero nonempty list halts by R4. The start list is 34 zeros then the digit 2 (nearest-first `repeat 0 34 ++ [2]`).
`init_reach` (literal, 6397 steps) gives c0 -->* Kc (repeat 0 34 ++ [2]) 0 0.

## Paper lower bound on sigma (NOT machine-checked; derived from the proved rules; Coq checks only halting)

Let beta = b+2. Rules: R1 doubles beta; R2 sends (x+1; b) to a = 2b+2 R1 steps, i.e. beta -> psi(beta) = 2^(2 beta - 1) per unit of the nearest digit.
Let A_n(D) = the b-value reached when the list [D, 0^n] (farthest first) is cleared from b = 0 to the all-zero list. From the rules (`absm.py` checks the
recursion against the abstract machine for A_0(0..2) = 0, 6, 32766 and A_1(1) = A_0(2)):
- A_0(D) = psi^D(2) - 2.
- A_n(D) = g_n^D(0), g_n(b) = A_{n-1}(2b+2) (R3 turns (y+1, 0^k) into (y, 2b+2, 0^(k-1)) and the sublist is cleared first).
- Lemma: A_m(D) + 2 >= 2↑^(m+2) (D+1) for all m, D >= 0 (induction on m; base psi(x) >= 2^x).
- Hence A_n(2) + 2 >= 2↑^(n+1) (2↑^(n+1) 3) for n >= 1.
Halting at the all-zero list of L digits scores sigma = 24 b + 2 L + 36 (literal check: `sig.py`, L = 1..3 digits, b = 0..5, 18 cases, all equal;
at least 24 b + 28 ones is clear from the final (101)-block run in `FIN`).
Our start (2, 0^34) is [D=2, n=34]: sigma = 24 A_34(2) + 106 > 24 (2↑^35 (2↑^35 3) - 2) + 106 > **2↑^35 (2↑^35 3)**.
The BB(7) champion starts from (2, 0^10) = [D=2, n=10] with the same rules: the same argument gives 2↑^11 (2↑^11 3), which is exactly the published bound
(a consistency check of the model). So the ratio of the two is 24 more arrows (35 vs 11). Since 2↑^k x is nondecreasing in k for x >= 2,
sigma(ours) > 2↑^11 (2↑^11 3). Exact sigma = 24 A_34(2) + 106 with A defined above (a closed recursion; not evaluable).
Caveat: sigma was derived at rule level plus literal tests of the final phase for small parameters. The lower bound needs only sigma >= b.
