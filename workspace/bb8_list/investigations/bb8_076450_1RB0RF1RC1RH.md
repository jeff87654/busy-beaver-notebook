# BB(8) holdout, subtask 76450: `1RB0RF_1RC1RH_0RD0RG_1LE0RB_0LA0LC_0LD0RA_1RD0LB_0RF---`

Source: holdout of BB(8) subtask 76450 (mxdys enumerator @ a41db6c). The undefined (halting) transition is H1.
Pipeline growth at 2 / 10 / 40 CPU-s was 7,414 / 16,129 / 31,179 digits at 1,749 / 2,309 / 3,276 loops
(4.24 -> 6.99 -> 9.52 digits per loop). The run was still going when it hit the time limit.

## Verdict

**The machine halts**, at the end of its second "level":

- sigma = (717984 · 36^123079 − 1114) / 35 ≈ **2.9345 · 10^191552** (191,553 digits);
- steps ≈ **8.8575 · 10^383104** (383,105 digits; exact closed form in `levels.py`).

It is **not a record candidate**: 10^191552 < 10↑↑4, far below the BB(8) bar 2↑¹¹2↑¹¹3.

**Confidence: proved (Coq PASS) for halting.** `bb8_list/proofs/BB8_76450_1RB0RF_1RC1RH.v` proves
`Theorem halt : halts tm c0.` (busycoq, Individual82, Coq 8.20.1):

```
compiled proofs\BB8_76450_1RB0RF_1RC1RH.v in 179.5s
PASS BB8_76450_1RB0RF_1RC1RH.v: 1RB0RF_1RC1RH_0RD0RG_1LE0RB_0LA0LC_0LD0RA_1RD0LB_0RF--- HALTS (machine-checked, no axioms)
```

The sigma and step values come from the recurrence below. Every rule was checked by exact literal simulation
(1,671 runs, 0 failures), and the step formulas reproduce the literal trajectory and Quick_Sim's trace to the step.
The sigma value is also read off the Coq proof itself:
- The halting configuration that `HaltN` reaches from N(2, m) is written out explicitly.
- It contains exactly 72m + 394 ones (the count is linear in m; checked at m = 0, 1, 2).
- `Theorem halt` uses m = G(123079, 279) = (9972 · 36^123079 − 207)/35.
- So sigma = 72m + 394 = (717984 · 36^123079 − 1114)/35.

## Configuration families

Tape order, blank outside the word; `p` is the part left of `10101000`, which the level rules never visit.

```
P        = p 10101000
L(p,X)   = P (0110)^X            F>1101      (head in state F on the first 1 of 1101)
M(p,x,y) = P (0110)^x 1010 (0101)^(y+1) H>0100   (head in state H on the 0 of 0100)
p1 = 1, p2 = 11010010
```

The Coq file uses the equivalent forms `N x m l = l (0011)^x 0 (0101)^m H>0100` (one transfer pass later,
N(x, y+7) is M(x, y) after that pass) and `Lv X l = l (0011)^X 0 F>1101` (= L).

and Start the whole left part is a variable, so there it is proved never to be read.
(`node check_rules.js 3 40 4 60 MSH` and `node check_rules.js 0 0 0 300 E`; outputs `check_rules_MSH.out`,
`check_rules_E.out`, step counts in `check_rules_steps_*.json`).

**Mechanism.**
- Two transfer loops (Coq `TAloop`, `TBloop`, by induction from the one-pass lemmas `TA1`, `TB1`):
  `(0101)^k 0100 (1010)^n F>1000 -> 0100 (1010)^(n+6k) F>1000` and
  `(1010)^k (0101)^m H>0100 -> (0101)^(m+6k) H>0100`. Each pass crosses the growing run twice, so a transfer
  multiplies the counter by 6 in quadratic time.
- One Mstep eats three (0110) blocks and does two transfers. On the N form (m = y+7) this is m -> 36m + 207.
- At the end of a level the counter is swept into the next level's blocks: F> (1010)^n -> (0110)^n F>
  (End1).
- End2 runs the same sweep but reaches the right end out of phase: state H reads a 1 and the machine halts.
  The final tape (from the Coq statement of `HaltN`) is a short prefix, then about 36y copies of 0110, with
  72y + 898 ones in all, and the head in state H on a 1 near the right end.

## Recurrence and why it halts

With y_0 = 272 and y_{j+1} = 36 y_j + 452, y_j = (9972 · 36^j − 452)/35. For j ≥ 1, y_j ≡ 2 (mod 3).

1. Level 1: blank -> L(1, 11) -> M(1, 6, 272). 6 = 3·2, so two Msteps give M(1, 0, y_2) = M(1, 0, 369236).
2. End1: L(11010010, 369244).
3. Level 2: Start gives M(p2, 369239, 272), with 369239 = 3·123079 + 2. After 123,079 Msteps the machine is at
   M(p2, 2, y_123079).
4. End2 halts, with ones = 7 + 72 y + 891 (ones(P2) = 7).

The residue is forced, not lucky: level 2 has X = y_2 + 8 blocks and y_2 ≡ 2 (mod 3), so X − 5 ≡ 2 (mod 3).

In Coq the counter function is `G k m` (m -> 36m + 207 on the N form). It is never evaluated. The only
arithmetic needed is `G 2 279 = 36 · G 1 279 + 207 = 3 · (12 · G 1 279 + 69)`, which `lia` checks with
`G 1 279` as an atom.

## Pipeline growth data

- Quick_Sim applies Iterated Rule 6 (×36 per application) at most 10 times per loop. That caps growth at
  10 · log10(36) ≈ 15.6 digits per loop.
- The observed 4.24 -> 9.52 digits per loop is the approach to that cap inside level 2. At 40 CPU-s the counter had
  31,179 digits, about 16% of the way to the final 191,551.
- The signal did not indicate super-tetration growth. The machine has only two levels before it halts.

## Record comparison and relation to the 1RB0RF_1RC0LF machine

- sigma ≈ 10^191552 is nowhere near 2↑¹¹2↑¹¹3, so this is not a record.
- The related non-halter `1RB0RF_1RC0LF_0RD0RB_1LE1LG_0LA0LC_0LD1RH_1RA1LC_1RF---` (7 transitions differ) has the
  same architecture: blocks pay for multiplications and a level end turns the counter into the next level's blocks.
  - There, the level residues lock into a non-halting 4-cycle.
  - Here, the residue after level 1 is forced into a halting ending at level 2.
- This machine is not a trivial variant of that one: the block (0110 vs 010), the rate (×36 per 3 blocks vs ×2 per
  block) and the level map all differ.

## Formal proof

`bb8_list/proofs/BB8_76450_1RB0RF_1RC1RH.v` is generated by `gen_coq.py` (382 lines; compiles in about
3 minutes).
- **Planner.** Phase scripts come from `planner8.py` and `pext.py` (copied from `../bb8_076450_1RB0RF1RC0LF`),
  with these extensions:
  - a halting stop;
  - a loop stop;
  - `m_concrete` now tries every block size;
  - `loops.py`: matchers for TAloop / TBloop and a run-rotation step (`rot4`).
- **Chains.** Long phases (Start, the halting ending) are cut at every transfer loop into segment lemmas (`St*`,
  `Hs*`). Each segment's concrete runs longer than 40 blocks are folded into a fresh variable, so the Coq terms stay
  small.
- **Hand-written parts** (inside `gen_coq.py`): `TAloop`, `TBloop`, the families `N` / `Lv`, `Ncyc`, `G`, `Niter`,
  `StartL`, `End1L`, `InitL`, `HaltN` (generated composition) and `Theorem halt`.
  - `Theorem halt` goes through `with_counter`, `halts_multistep` and `halted_halts`.
  - The final configuration has state H on a 1 (`tm (H, 1) = None`).
