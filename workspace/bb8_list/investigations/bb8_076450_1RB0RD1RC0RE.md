# BB(8) holdout, subtask 76450: `1RB0RD_1RC0RE_1LD1LC_1LA0LD_1LB1RF_---1LG_0RB1RH_0LB1RG`

Source: holdout of BB(8) subtask 76450 (mxdys enumerator @ a41db6c). Pipeline growth at 2 / 10 / 40 CPU-s was
9,297 / 16,970 / 31,257 digits at 1,287 / 1,780 / 2,698 loops (7.22 -> 9.53 -> 11.59 digits per loop). All runs
stopped at the time limit. The only undefined transition is F0.

## Verdict

**The machine never halts.** It is a tetration-rate counter that never reaches F0.

**It is not a record candidate.** A non-halter cannot be a BB(8) champion.

**Confidence: proved (Coq PASS).** `bb8_list/proofs/BB8_76450_1RB0RD.v` proves `Theorem nonhalt : ~ halts tm c0.`
(busycoq, Individual82, Coq 8.20.1, compiles in about 21 s, no axioms). `python check.py` printed:

```
PASS BB8_76450_1RB0RD.v: 1RB0RD_1RC0RE_1LD1LC_1LA0LD_1LB1RF_---1LG_0RB1RH_0LB1RG never halts (machine-checked, no axioms)
PASS BB8_76450_1RB0RD_H0_1LC.v: 1RB0RD_1RC0RE_1LD1LC_1LA0LD_1LB1RF_---1LG_0RB1RH_1LC1RG never halts (machine-checked, no axioms)
```

**H0 variant `..._1LC1RG`: never halts too.** The conclusion carries over, and it is proved in Coq with the same
lemmas and proof scripts (`BB8_76450_1RB0RD_H0_1LC.v`, PASS above).
- In the main machine, H0 is read only at the turn of rule O, where it starts the detour H0 0LB, B1 0RE, E0 1LB,
  B0 1RC, C1 1LC. The variant's single step H0 1LC leaves exactly the same tape, head and state.
- So the variant runs through the same configurations. It is 4 steps faster per rule O.
- Checked at all 2,768 H0 reads of a 2·10^7-step literal run (`h0ctx.py`, `h0ctx_main.txt`), and by the literal
  trajectory below.

**The hint about the proven halter does not carry over.** This machine shares rows B–E with the halter
`1RB1LG_1RC0RE_1LD1LC_1LA0LD_1LB1RF_1RC1LG_---0LH_1RA1LF` (`bb8_076450_1RB1LG1RC0RE.md`), but its counter is different:
- The counter is a run of 0s, not a block of (011) digits. Each digit (3 cells) sends a to 6a+6, not n to 4n+2.
- The resets are decided by the residue of b mod 3 and by the tail.
- The residue of the next b is forced (6a+7 ≡ 1 and 6a+3 ≡ 0 mod 3) for every a. So, unlike the halter's mod-6
  reset, no reset can ever pick a halting branch.

## Configuration family

Head in state A on the blank cell just left of the word; `t` is one of two tails, blank beyond:

```
M(a, b, t) = 0^inf A>0 1^6 0^a 1 0^b t,      T1 = 1111001 0^inf,    T2 = 111 0^inf
```

**Mechanism.**
- **Rightward sweep:** A0 1RB, B1 0RE, E1 1RF, F1 1LG, then G1 1RH / H1 1RG sweep right over the 1s. F reads cell 3,
  so it reads a 1 whenever there are at least three 1s.
- **Turn:** the parity of n decides which state reaches the first 0.
  - **n even (H0):** the turn leaves 1 0 1^(n+1), and C sweeps back left (C1 1LC). Then L turns this into 1^(n+6)
    and eats one 0 of the zero run. This is rule O.
  - **n odd (G0):** G0 0RB, B0 1RC, C0 1LD. Then a marker 1 walks left (A1 0RD, D1 0LD, D0 1LA), erasing the whole
    run: rule R, or rules Z and W at the tails (with D1 0LD).
- So the run of 1s grows by 6 per 0 eaten. When the zero run is used up, rule R turns the 6a+7 ones into the new zero
  run 0^(6a+6) and takes 3 cells from b.

## Invariant and trajectory

Invariant: `Inv(a, b, T1) = M(a, 3b, T1)` and `Inv(a, b, T2) = M(a, 3b+1, T2)`, for all a, b >= 0.
- From M(a, 3(b+1), T1) or M(a, 3(b+1)+1, T2), the digit rule applies and the result is again in Inv.
- From M(a, 0, T1), reset Z gives M(4, 6a+7, T2) = M(4, 3(2a+2)+1, T2).
- From M(a, 1, T2), reset W gives M(4, 6a+3, T1) = M(4, 3(2a+1), T1).

So exactly one rule applies to every member, each takes at least one step, and the result is again a member. The
blank tape reaches M(4, 1, T2) at step 82, so the machine never halts. The Coq proof is exactly this argument:
`Inv_step`, `progress_nonhalt_simple` and `multistep_nonhalt`.

Trajectory, with f(a) = 6a+6, so f^k(4) = (26·6^k − 6)/5 (`sizes.py`, `sizes.out`):

| --- | --- | --- | --- |

| 1 | M(4,27,T1) | 9 | M(a1,0,T1), a1 = f^9(4) = 52,404,018; reset Z: M(4, 314,424,115, T2) |

Each phase adds one exponential level (a_{j+1} ≈ 6^(2a_j)), forever.

**Literal check** (`trajectory.js`, 1.2·10^10 steps, no acceleration):
- It finds every M-configuration and checks that each is the predicted successor of the previous one, reached after
  exactly the predicted number of steps.
- Main machine (`trajectory_main.txt`): 8 configurations, 0 mismatches, from M(4,1,T2) at step 82 up to
  M(242610,9,T1) at step 10,091,998,235.
- H0 variant (`trajectory_H0_1LC.txt`): the same 8 configurations with the variant step counts, 0 mismatches. It
  reaches M(242610,9,T1) at step 10,091,804,163.

**Why the pipeline saw 7–12 digits per loop.**
- The pipeline was inside phase 2. Its digits are the digits of the ones count, which is about 6a while the run of 1s
  is on the tape, and a gains log10 6 ≈ 0.78 digits per digit rule.
- So 9,297 / 16,970 / 31,257 digits is about 12,000 / 22,000 / 40,000 of the 1.05·10^8 digit rules of that phase.
- Quick_Sim (block size 2, `qs_prover400.txt`) proves our rule O as its "Diff Rule 0/1" (`11^6 00^-1`). At 400 loops
  it is at the end of phase 1 with 314,424,108 ones = 6·a1.
- 11.59 digits per loop is about 15 digit rules per loop. That is ordinary acceleration of an exponential phase. The
  super-exponential part is the phase structure above.

## Formal proof

`bb8_list/proofs/BB8_76450_1RB0RD.v`, generated by `gen_proof.py main` from `proof_template.v.in`:
- **Crossing lemmas:**
  - `cr_GR`: G/H rightward over [1;1];
  - `cr_CL`: C leftward, keeping the 1s;
  - `cr_DL`: D leftward, erasing;
  - `cr_AL`: the A/D marker walking left over [1;1] and leaving [0;0].
- **Tape rules** `O`, `Rp` (progress form; `Rs` is the `-->*` form), `L`, `Zp`, `Wp`: each is `execute`, the
  crossings, a fixed number of `step`s, then tape normalization.
- **Family rules** on `Mc a b t`: `Oiter` (a rules O, by induction), then `step3`, `stepZ`, `stepW`.
- **Main theorem:** `init_reach` (82 steps), then `Inv_step` and `nonhalt`.
