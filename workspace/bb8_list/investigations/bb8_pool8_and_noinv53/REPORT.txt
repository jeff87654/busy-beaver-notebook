3. Exact Conservation Law & Asymptotic Growth Rate
--------------------------------------------------

tail block `00101` contains exactly ONE 1-word (`001`). Thus the total number
of 1-words outside the header is k + m:
  - Non-carry step: delta_k = 0, delta_m = +2  => delta(k + m) = +2.
  - Interior carry: delta_k = 0, delta_m = 0   => delta(k + m) = 0.
  - Overflow carry: delta_k = +1, delta_m = -1 => delta(k + m) = 0.
In epoch k, there are (3^k + 1)/2 non-carry increments, so delta_m = 2*(3^k + 1)/2 - 1 = 3^k.
