## Verdict

**The machine never halts. Confidence: proved (Coq PASS) -- see the status line below.**
- It is a two-level counter whose second level holds at most one digit. The digit is used up after 5 + 122471 "rounds"; after that a
  digit-free loop `a -> 6a + 40` runs forever. Growth is exponential in the number of loops (about 6^n for n loops, each loop costing
  about 100 a^2 steps): a doubling-class signature with NO tower. It has no sigma and is **not a record candidate**.
- Proof: `bb8_list/proofs/BB8_016582_1RB0RC.v` (`Theorem nonhalt : ~ halts tm c0.`, busycoq, Individual82).
  `python check.py BB8_016582_1RB0RC.v` prints (`bb8_016582_1RB0RC1LA1RF/check_py.out`):
  `PASS BB8_016582_1RB0RC.v: 1RB0RC_1LA1RF_0RE0LD_1LE0LH_1LA0LG_1RA0LF_0LC1LE_---1LF never halts (machine-checked, no axioms)` (compile 906 s).
- The halting cell H0 is never reached: every family configuration has a successor in the family.

**Sibling variants (the two machines that differ in G0: `0LC` -> `1RE` / `1RB`, queue digits 10,187 / 9,744): NOT covered by this

## Configuration family

Head in state A on the blank cell left of the word (blank tape left):
```
X(m,a,r) = 0^inf A> 0 11 (01)^(3m+2) 0^a U r          U = 1 0000 1 0 1
Y(m,a,r) = 0^inf A> 0 11 (01)^(3m+1) 0^a U r
Dg(d)    = 0^d U 0^inf                                a digit d
```
The tape from the head is the counter `(01)^j` with j = 3m + 2 (or 3m + 1) and the gap a; `r` is a list of digits. A digit is a gap
`0^d` followed by the unit U. The run (j, a) turns the gap a into 3a extra pairs of the counter, one unit of a per sweep.

## Orbit and why the halting residues never occur

1. blank tape --1396 steps--> X 0 14 (Dg 44) (`init_reach`; the literal simulator agrees: this is the config of step 1396).
2. Five rounds: the digit 44 -> 4, a: 13 -> 118 -> 748 -> 4528 -> 27208 -> 163288 (literal simulation confirms the first two rounds:
   step 5570 has a=119 and digit 36, step 149290 has a=749 and digit 28).
3. `pop` uses the digit 4: the new digit is 41 + 6*163288 = 979769 = 8*122471 + 1. Only the residue mod 8 matters: a digit is used
   up by 8 per round, so a digit d ends at the value ((d-1) mod 8) + 1. Rules exist for the ends 1 (C1) and 4 (N2p) only.
   The new digit is 41 + 6a with a = 163288 = 0 (mod 4), hence = 1 (mod 8), which is the end C1. (Digits ending at 2, 3 or 5..8 would need
   other rules; the digits 44 and 979769 end at 4 and 1, so those cases do not occur.)
4. 122471 rounds (digit 979769 -> 1), then `fin1` to the digit-free configuration X 0 (S a) 0^inf.
5. `Fc_step` loops for ever: a -> 6a + 40 (N1 x a, then N2s).
The only digits ever created are the digit 44 (initial) and the digit 979769 (after `pop`); the list never has two entries.
