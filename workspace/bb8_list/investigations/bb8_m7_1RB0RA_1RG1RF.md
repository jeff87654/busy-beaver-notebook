## Non-halting argument (proved, theorem nonhalt)

step_fam: for every (ds, a, b) with ds <> [] there is a successor Kp ds' a' b' with ds' <> [] reached by -->+ (a > 0: R1; a = 0 and all-zero list: R4; a = 0 and
the nearest nonzero digit has no zero before it: R2; with zeros before it: R3). It is used with progress_nonhalt_cond. init_reach : c0 -->* Kp (repeat 0 29 ++ [2]) 0 0
is literal (do 4775 step). No lexicographic argument is needed, unlike the halting champion: the rebuild always produces a longer nonempty list.
The empty list K([];0;b) is never reached (R1-R3 preserve the length, R4 lengthens it, the start has 30 digits) and is not covered by the proof (literally it also
rebuilds, to 12b+7 digits).

## Lessons for the next rebuilder (p2/p3 or others)

1. A loop shows up in the planner as an endless PEEL / crossing cycle. Do a dry run with peel_limit = 0 to get the configuration at the next iteration, use it as the
   target of the iteration lemma (TLP), and prove the loop by induction (TLPS).
2. Do not trust a guessed start for the loop exit: run the literal simulator, find the configuration (scanE0.py), test it alone (e0lit.py), and only then let the
   planner find the finishing pass (stop_when).
3. follow needs a -->* lemma; for -->+ lemmas use: eapply evstep_trans; [apply progress_evstep, L |].
4. Drop a trailing 0 before const 0 in hand-written starts (the planner does), otherwise lemma endpoints differ syntactically.
