2. PIPELINE
  Stage 1 (tools/tslit.exe, src/tslit.cpp): literal blank-tape lockstep against the base's (write,move) trace for 1e7 steps,
    lazy branching on H.  Leaf S = same trace for 1e7 steps (engine intact in level 0); X = diverged; H = halted.
  Jump battery: tools/batt.exe with battery1.txt (3780 small Kt configs, tail t = 0..6, 10 far contexts, JCL/JR1 shapes);
    tools/batt231.exe with battery231b.txt (208 Kc configs) for champ_231/232.  Child vs base lockstep inside the jumped
    region only (trace cut at the jump target).  Tried from every candidate canonical state (clone splits), lazy reads
    branched.  This validates that the follower's jumps are the child's real behaviour.
  World follower (a)/(c): pkf8t (from bb9_topmap_all) in W2 (--B 66 --cls 66 --mod 150), driven by tools/wtree.py with TNF
    branching on lazy slots.  tools/pkf8q.exe = pkf8t + --qset (canonical moment in a clone state); md5-identical on M8.
  World follower (b): tools/c231f.exe (src/c231f.cpp) with the Coq rules R1ITER and CDP (C231_rules2.v, C231_clear.v).
    Exact while < 1e9, else a representative R.  --fixed: R = max(RC, m+1) rounded into 39 mod 81, so 2R+3 = 0 mod 3^5.
  Halt reachability (tools/haltreach.py): static state reachability, then bb8_resid backref_s at depth 40.
  Escalation count (tools/rank.py): a clear with k >= 300 that exceeds the previous clear's k by >= 100.

5. WHY (short)
  Every slot of the champion is an engine slot, so a second change keeps the engine only as a clone split or a guard.  The
  battery shows that no child with E0 -> H plus one more change alters a jumped (clearing/R1) context.  These children
  therefore differ from set8 rows only in the literal exhaustion processing, where H is the only free state.  That is the
  set8 situation, whose best row is M8.  The extra freedom (E0 freed by a clone split) yields only the Z mechanism (halt
  when G crosses 00), arithmetic rebuild loops, or round-1 halts.

7b. CLONE-SPLIT / QSET BLIND SPOT (found and fixed mid-run)
  A clone-split child can reach the canonical moment in its clone state.  For base (a) that is H with H0 = B0's move; for
  champ_231 it is F or H with E0's move.  pkf8t and c231f only jumped in the base's state (B, resp. E), so such children
  ran literally and stalled.  The battery also started in the wrong state, which failed them spuriously.
  Fix:
    * src/pkf8q.cpp = pkf8t + --qset; the state is kept across a jump.  It gives md5-identical output on M8.
    * c231f takes --qset.
    * batt and batt231 try every candidate start state whose 0-slot makes the base's Q0 (write,move), and print "PASS ... qset=XY".
  Status: the (a)/(c) world tree ran BEFORE the fix.  Rows whose K-state is not B may have stalled in W2, mostly as STOP_NEEDK
  rows.  The rerun is item (3).
  OPEN_CANDIDATES.txt: nothing appended (no machine with strong evidence of >= 3 rounds then halt).
