         merging all `k` zero digits into the single block of `1`s to their right
         (`1^N -> 1^{N+2k}`) with NO `0` separators between them!
      4. The leftward pass only stops when it hits a non-zero digit `d >= 1`
         (`1^{d+1} 0`), where `F0=0RB` sees `1` instead of `0`, triggering `B1=1RF`
         to start the rightward multiplication pass. That rightward pass writes
         one `0` at `G0=0RA` and multiplies the merged `1^{N+2k}` block into a
          SINGLE digit `3b + 6k - 1`!
    Because the leftward pass erases separators (`10 -> 11`) and the rightward
    pass only ever writes a single separator at `G0`, `k` consecutive zeros are
    topologically guaranteed to collapse into 1 digit (`len -> len - k + 1`).

  * Note on `max_n = 79` neighbor (`1RB0LF_1RC1RG_1LD1RE_0LA1LD_---1RA_0RB1RG_0RA0LE`,
    `B1: 1RF -> 1RG`): Here even `B1` (`k=1`) contracts (`K([..., d, 0]; 0; b) ->
    K([..., d-1+3b+4]; 0; 2)`), so its 79-digit list `[2^79]` simply shrinks by 1
    digit every ~30 steps without building an Ackermann tower.
