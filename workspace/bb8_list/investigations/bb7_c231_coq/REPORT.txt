PROOF STRUCTURE
  Kc ds a b = 0^inf E> 0 1^(2b+1) 00 1^(2a) 00 [1^(2d) 00 for each digit d, nearest first] 1 0^inf
  C231_rules1/2/3: crossings, mini-cycle MC, R1ITER (Kc ds a b -->* Kc ds 0 (b+3a)), the passes START/FW/TURN/BW/FINB,
    R23 (k <= b: Kc (0^k ++ S y :: t) 0 b -->+ 0^inf E> 0 1 00 (1100)^k 1^(2(b+3-k)) 00 rgt (y::t)), giving
    R2 (k=0) and R3 (k>=1: Kc (1^(k-1) ++ (b+3-k) :: y :: t) 1 0), and R4x (k <= b: Kc 0^k 0 b -->* cfin k b, halted,
    ones = 2b+7).  Every lemma statement was literal-checked first (tools/rules.py, onescheck.py; both machines).
  C231_init: c0 -->* Kc (1^20) 1 2 (231: 3715 steps; 232: 3775 steps, by `do N step`).
  C231_clear: CDP (clearing a digit at depth m from counter B >= m, by induction on the depth), clear_ones.
    The k <= b side condition of R3/R4 always holds because W j B >= B + j and U j x >= x + 1.
  C231_run: c0 -->* Kc (1^20) 0 5 -->* Kc (0^20) 0 (W 20 5) -->* cfin 20 (W 20 5); count of ones.
  Bound.v: U_lower: arrow i 3 (y + 3 - i) <= U i y; W_chain: Lc j + j <= W j 5; comparisons.
  Bound3.v: W j 5 >= arrow j 3 3 + j for j >= 2 (base W 2 5 = U0^26(3) >= 2 * 3^27 = 2 * arrow 2 3 3).
  Comparisons with closed arrow terms are done only by exact proof terms + arithmetic lemmas on variables
