- AFFC: affine k-fold rules were refused when a congruence on the growing variable appeared (e.g. 2*x0+2 = 0 mod 2).
  Now a congruence N = r (mod q) is admitted when x -> a x + c leaves it invariant: a_t (a_t-1) = 0 and sum a_t c_t = 0
  (mod q) (N(f(x)) = N(x) mod q for every x); it is checked at the first application.
- Proof-mode affine k-fold: proof symbol Z sub 'A' (A=a, J=c, K=k, B=x); LB by iterating min(lb k,128) times; residue
  from the orbit of r -> a r + c mod MG indexed by k (k mod period when symbolic, requireLB(k, orbit length)).
- ITER rules (proofRun): counters x_u -> x_u + delta_u (delta < 0 limits k), constant resets, ONE self map
  x_v -> F(x_v) where F is a Lin over proof symbols (A/P/C/T, nonnegative coefficients = monotone) depending only on x_v,
  constant resets and at most one increasing counter j (v14).  k-fold F^k(x0) = T(k, x0): orbit of iterates, each
  abstracted by a fresh symbol (lower bound, residue mod MG), j by "j >= 64, residue unknown (mod 1)"; cycle detection on
  (residue, saturated lb, j-abstraction); exact k indexes the orbit, symbolic k needs k >= orbit length and period | MG.
  Soundness: every constructor's value (lower bound, residue) is a function of its arguments' (lower bound, residue)
  and is monotone, so the abstraction covers all real iterates; constraints are re-checked at every abstracted iterate
  (IterStop truncates k to the valid count).  Symbolic k also requires the growth witness F(y) >= y+1 (linear lower bound
  alpha*y + beta via Bernoulli a^K >= 1 + (a-1)K, alpha >= 1).  Proof-mode ITER: proof symbol Z sub 'T' (rp = rule,
  B = x, K = k, J = counter start) -> nested levels (tower, iterated tower, ...).
- Plumbing: failed proofs roll back GS (no symbol leaks); bad_alloc inside a proof = failed proof; proof retry at
  powers of two recurrences; orbit / result / affine-orbit caches with size caps; --rulecheck (AFF/ITER rule instances vs

  X ->E Y meaning X >= 2^Y,   X ->L Y meaning X >= Y,

form f is accepted only when Y's coefficient in f is >= the denominator and every other coefficient and the constant are

       Lemma: U_j(y) >= 2^y and U_j(y) >= y + 1 (induction on j: U_0 directly; U_j^m(0) >= m and
