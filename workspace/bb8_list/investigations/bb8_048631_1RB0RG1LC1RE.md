## Rules (all proved in Coq for all parameters; "k" = number of trailing zero digits, nearest first in the Coq lists)

| rule | statement (mirror notation) |
| --- | --- |
| R1 (a >= 1) | K(ds; a; b) -> K(ds; a-1; b+1) |
| R2 (k = 0, b >= 1) | K(.., x+1; 0; b) -> K(.., x; b+1; 0) |
| R3 (1 <= k < b) | K(.., y+1, 0^k; 0; b) -> K(.., y, b+1-k, 1^(k-1); 1; 0) |
| R4 (digits all zero, b >= 1) | K(; 0; b) -> K(1^b; 1; 0) |
| k >= b | not characterized (unreachable). Raw probes: k = b gives K(.., y-1, 2, 1^(k-1); 1; 0) for y+1 >= 2, no halt; k = b+1 gives K(.., z+1, 1^(b-1); 1; 0); k >= b+2 gives K(.., z, 0^(k-b-2), 1^b; 1; 0). None halted for b = 1..4, k <= b+4. |

(The scan's "k = b" exception is just that: R3 is only valid for k < b.)

Machine-level phases (planner8.py exact symbolic execution; each one is a Coq lemma, see `gen048.py`):
- `R1P` (38 steps + crossings): `A> 0 1 1 1 (01)^b 0 0 1 0 l -> A> 0 1 1 1 (01)^(b+1) 0 0 l`.
- `TR0`: `A> 0 1 1 1 (01)^(r+1) 0 0 0 w -> (0 1 1) A> (01)^(r+2) 0 0 w` (37 steps + crossings): first right sweep, left stack gets a block `011`.
- `LOOP`: `l A> (01)^(r+2) 0 0 0 w -> (0 1 1 l) A> (01)^(r+1) 0 0 w` (15 steps + 4r): one zero of the gap moves into a block, one (01) of b is spent.
- `FINS/FINZ` (y = S y' / y = 0): `(0 1 1 0 l) A> (01)^(r+2) 0 0 1 (01)^y rr -> (0 1 1 0 l) A> 0 1 1 1 (01)^(r+1) 0 0 1 (01)^y' rr` (the digit decrement).
- `TRN`: `(0 1 1 0 l) A> 0 1 1 1 w -> (0 l) A> 0 1 1 1 0 0 1 w` (9 steps): moves a block back to the right as a `001` digit.
- `END` (run exhausted, blank gap): `(0 1 1 0 l) A> 0 1 const0 -> (0 l) A> 0 1 1 1 0 0 1 const0` (13 steps).
- `RES` (R2/R3): TR0, k x LOOP, FIN, (k+1) x TRN gives `A> 0 1 1 1 (001)^(k+1) 0 1 (01)^r 0 (01)^y rgt t`, i.e. refill r+2 = b+1-k.
- `R4`: TR0, (b+1) x LOOP, END, b x TRN.

## Why it never halts (the invariant; same lemma skeleton as `BB8_240161_1RB0RA.v`)

- `R1iter`: K(ds; a; b) -->* K(ds; 0; B) with b + a <= B.
- `CH`: for b >= 1, K(x::U; 0; b) -->* K(0::U; 0; B) with b + x <= B (R2 then R1 x (b+1)).
- `EX`: K(1^j ++ (w+1)::U; 1; 0) -->* K(0^(j+1) ++ U; 0; B) with B >= w + 1 + j + 1.
- `IN`: if k = j+1 < B then K(0^(j+1) ++ v::U'; 0; B) -->* K(0^(j+2) ++ U'; 0; B2) with B2 >= B + v. R3 applies because k < B, the refill is B-k+1 >= 2, `EX` clears it with b >= B + 2, and induction on v continues.
- `CLR`/`GEN`: any configuration with all digits nonzero reaches the all-zero family Zc, and every reset on the way has k < b. A rebuild (R4) gives 1^b (all nonzero), so `Top B -->+ Top B'` for every B. The cycle never meets k >= b. Note the margin is thin (min b - k = 1 in simulation), but exact.
- `init_reach`: 54 literal steps from the blank tape give K(; 1; 0); then `GEN`.
