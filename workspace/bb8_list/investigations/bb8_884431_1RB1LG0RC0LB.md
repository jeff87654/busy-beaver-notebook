## Why it never halts (the invariant)

Invariant `OddLen`: the digit list has odd length. `step_good` (Coq): every Kc ds a b with odd |ds| has a successor Kc ds' a' b' with odd |ds'|:
- a >= 1: R1 (same list). a = 0 and a nonzero digit exists (ds = 0^k ++ (y+1) :: t): R2 (k = 0) or R3 (k >= 1), list length unchanged.
- a = 0 and all digits zero, n = |ds| odd: n = 1 gives Z1 (length 3), n = 2u+3 gives Z3 (length 2b+5). Both odd.
- Even n never occurs. `progress_nonhalt_cond` closes the argument; `init_reach` gives K([0,0,3];0;0) from c0 in 159 steps.

No halting transition is used in any lemma, so no analysis of the orbit is needed. The real orbit has not even finished its first epoch in
simulation (list [2, 0, d] with d counting down).
