2. THEOREM A (no faithful 9-state extension of M8 is class-robust)
-------------------------------------------------------------------
Let V be a 9-state machine whose computation from the blank tape coincides with M8's up to M8's halting configuration,
in the sense that V contains M8's 16 defined transitions (up to renaming) and reaches Hc in a state X reading 1 at the
moment M8 halts, in every class.  Then V does NOT satisfy "sigma(V) > sigma(M8) in every class".  More precisely V is one of:
  (i)   never halts (in any class);  (ii) halts in every class with sigma(V) <= sigma(M8);
  (iii) halts immediately with sigma(V) <= sigma(M8) in the d = 0 classes and continues in the d >= 1 classes (Y1's type);
  (iv)  halts immediately with sigma(V) <= sigma(M8) in the d >= 1 classes and continues in the d = 0 classes.
Proof.  Slot budget: V has 18 slots; the 16 M8 transitions occupy 16 of them (two M8 states cannot share a V-state since
no two M8 states act alike, and a V-state that clones an M8 state in some contexts costs its two slots there), so V has
exactly two further slots I0, I1 plus the slot X1 that M8 leaves undefined.  V halts only through an undefined slot, and
an undefined slot among the 16 would stop the M8 computation early; so exactly one of X1, I0, I1 is undefined.
  * X1 undefined: V = M8 up to an unused state: (ii) with equality.
  * X1 = w D Q with Q an M8 state (including X itself): I is never entered (no M8 transition targets I), so the undefined
    slot is unreachable: (i).  (Q = X: X1 = wRX sweeps right over E's 1s forever or, with w = 0, erases to the right and
    then X0 = 1RG re-enters the engine without a halt slot; X1 = wLX reads d-dependent cells but again I is unreachable.)
  * X1 = w R I: by (F1)/(F3) I reads 1 at every entry.  If I1 is undefined: V halts at once in every class with
    sigma(M8) + (w - 1) <= sigma(M8): (ii).  Else I0 is undefined and I1 = w' D' Q'.  Q' = I, D' = R: sweeps right over the
    1s and halts at the first 0 (no new 1 written: (ii)).  Q' = I, D' = L: reads w; w = 0 halts at once, w = 1 sweeps
    left over 1s and halts at the first 0, at most one cell further ((ii)).  Q' an M8 state: I is re-entered only via X1
    (by (F3) always reading 1), so I0 is unreachable: (i).
  * X1 = w L I: by (F2) I reads 0 in the d >= 1 classes and 1 in the d = 0 classes.  The undefined slot is I0 (then (iv):
    the d >= 1 classes halt at once with sigma(M8) + w - 1) or I1 (then (iii): the d = 0 classes halt at once with
    sigma(M8) + w - 1).                                                                                               QED
Remarks.  (a) The d = 0 classes (31/0, 31/4) are Coq-proved to be M8's endgames for those (key, rho); whether the REAL run is
in one of them is the uncomputable question of section 3, so (iii) can never be upgraded.  (b) Ties (sigma = sigma(M8)) are
not records.  (c) bb8-resid's 288-machine F1 screen (H1 -> I) is consistent with the theorem: every xRI row either halts
immediately (ones 24964 = M8) or runs on without a halt; xLI rows split by d.  y1-deep's suggestion to prefer right-moving
H1 = xRI extensions is therefore void: they cannot halt.  (d) The theorem does not depend on how Y1 behaves later: in the
d >= 1 classes Y1 may do anything (y1-deep: rounds of further escalations with class-dependent halts), it is already lost
in the d = 0 classes.

3. THE CLASS QUESTION: WHY NO INVARIANT CAN DECIDE IT
-----------------------------------------------------
3.1 Exact dependence (Coq).  The level-B cascade is one orbit of gstep(L) = (3L + c_{L mod 5})/5, c = (-100, 32, -46, -64,
-52) for L mod 5 = 0..4, from L1 = gstep(L0), L0 = 36B + 73 (Step.v).  At L1 the parked count is P = 12 R2 + 11 (reach_top)
and one g-step consumes 3 / 11 / 4 / 6 / 6 parked zeros for L mod 5 = 0 / 1 / 2 / 3 / 4 (CascU.casc_stepU).  The key is the
first orbit value < 60 (in {31,37,43,49,55} by parity and mod 3); for key 31 the route is rho = (P - 35) mod 5 (K31_End).
With R2 = 1 mod 5:  rho = (3 - sum_i cost(r_i)) mod 5 over the orbit from L1 to the key.  So the class is a function of the
residue sequence r_i = L_i mod 5, and r_i is determined by L1 mod 5^(i+1): given r_0..r_(i-1), r_i is a bijective function of
the i-th base-5 digit of L1.  Hence EVERY residue sequence is realised by some start, and the orbit of the real start is
pinned only through the exact value of B = (2^^13 3 - 4)/2: its first k residues through B mod 5^k (computable for any k by
iterated Euler, towermod), the rest not.  The orbit has about log_(5/3)(36B) = 1.36 T steps, T = 2^^12 3.

3.2 LEMMA B (no additive residue invariant).  Let m >= 2 and let Q : Z/m -> A (any abelian group) and h : Z/5 -> A satisfy
Q(g(L)) - Q(L) = h(L mod 5) for all L >= 60.  Then h = 0.
Proof.  Write m = 5^k m' with gcd(m', 5) = 1.  (a) k = 0: for each r the branch x -> 5^(-1)(3x + c_r) is a well-defined map
on Z/m' and has a fixed point, namely the solution of 2x = c_r (mod m'), which exists because every c_r is even (and 2 is
invertible when m' is odd).  Taking L in that class with L = r mod 5 (CRT) gives h(r) = Q(fix) - Q(fix) = 0.  (b) k >= 1:
for x in Z/m and its five lifts x' = x + j 5^k m' (j = 0..4) the images g(x') = g(x) + 3 j 5^(k-1) m' run through all classes
mod m that are = g(x) mod 5^(k-1) m', and all have Q(g(x')) = Q(x) + h(r).  Every class mod m is such an image (3x + c_r = 5y
is solvable in x for every y, and the solution automatically has x = r mod 5), so Q is invariant under translation by
5^(k-1) m', i.e. Q factors through Z/(5^(k-1) m').  Induct down to k = 0.                                             QED
Consequence: no quantity of the form (P + a L + b t + ...) mod m, and no automaton that only accumulates a group element per
residue read, can relate rho (an additive residue functional of the orbit) to anything computable about the start.
(C04's parity invariant is NOT a counterexample: there h = 0 and Q = L mod 2 is a conserved quantity, which constrains the
key set but says nothing about the sum of costs.)

3.3 Monte Carlo in the real residue class (mc_class.py, runs/mc_class.txt).  Starts L0' = L0 (mod M), M = 2^12 3^6 5^6
7 11 13 17 19 23 29 31 (B's residues from towermod), 20000 samples each with 80, 300 and 1500 decimal digits, exact
accounting of 3.1.  Every one of the nine classes occurs in every size; key 31 has 0.50-0.55 total weight split evenly
over rho = 0..4; the d = 0 classes have weight 0.204, 0.218, 0.219.  (The real orbit's first 5 steps are fixed by 5^6;
they do not matter.)  So within everything that is computable about B by residues, Y1's outcome is 78/22.

3.4 What deciding the class would take.  L0 = 18 * 2^T + 1 with T = 2^^12 3.  After n steps 5^n L_n = 3^n L0 + S_n with S_n a
signed sum of 3^(n-1-i) 5^i c_(r_i); the key is L_n at the first n with L_n < 60, n = 1.36 T.  Knowing the class means knowing
L0 mod 5^n up to the equivalence "same orbit tail", i.e. essentially the base-5 digits of 2^T at positions up to 1.36 T
(3.2 T bits), where 2^T itself has T bits: there is no reduction of the exponent (T < 4 * 5^(n-1)), and no method is known
to produce a middle base-5 digit of a power of 2 without computing all lower digits.  Hence: decidable in principle (it is a
fixed integer), not decidable by any known means, and by 3.2 not decidable by residue invariants of any modulus.

3.5 Consequences for Y1.  Certified: sigma(Y1) >= sigma(M8) - 1 (all classes), and sigma(Y1) > sigma(M8) iff d >= 1.
Y1 is a BB(9) record with heuristic probability about 0.78 and cannot be certified.  In the d >= 1 classes y1-deep found
rounds of further escalations (each round a top rebuild of ~12R, f_w^3, f_w^4, ...) with class-dependent halts inside each
round (every H1 event is a potential halt, decided by residues of tower-sized tokens); even conditional on d >= 1 the
number of escalations is not computable, and the halting itself is only heuristic (probability 1).  No Coq target exists.

4. THE REAL OBSTRUCTION, IN ONE SENTENCE
----------------------------------------
M8's halting head sits on the last 1 of a class-dependent token D(d) with d = 0 in two of the nine classes, and a 9-state
extension has exactly one new decision (I's first read): left of the head it reads d, right of it it reads a constant 1
that leaves no halt slot.  Any certifiable improvement must therefore diverge from M8 BEFORE its endgame.

5. BEATING M8 WITHOUT KNOWING THE CLASS
---------------------------------------
5.1 Criterion.  M8's score satisfies f_w(f_w(12B+26)) < sigma(M8) < f_w(f_w(12B+27)) (Coq, EndU bracket), and the whole
endgame analysis of C04/M8 covers every class.  A machine V on the same engine with the same marker exhaustions (hence the
same sub-step rules R2, the same endgame tables R3/R4) but a LARGER second escalation has K' = 12 R2' - 10 - Q' with
R2' >> R2, so its all-class lower bound f_w(K'+1) exceeds f_w(f_w(12B+27)) regardless of which class it ends in.  Its
halting proof is C04's proof with a different exhaustion-#1/#2 lemma.  This is the only kind of certifiable 9-state record on
M8's engine that the slot budget permits.

exactly three are defined.  M8's halt H1 must stay undefined (an M8-like D0 endgame is the only halting mechanism we can
prove), so H0, I0, I1 are defined and I must be entered from H0.  H0 = xRI makes I read E's 1 and I0 dead; H0 = 1LI cannot
