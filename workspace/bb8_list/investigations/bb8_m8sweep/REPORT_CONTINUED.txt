4.1. Two Structural Artifacts in wf.cpp Explaining Non-225 T/XMAX Leaves
Every single one of the 2,682 T (esc >= 2) and 34 XMAX (esc >= 2) leaves outside
Base 225 is a non-halting loop caused by one of two artifacts in wf.cpp:
  1. Loop-Detector Blind Spots (wf.cpp lines 182-186):
     - Exponential rebuilds with k_{r+1} = 2 R_r + c or 3 R_r + c (such as
       zeros = [3 69 189 429 909] or [92 88 308 668] or [13 52 142 232 412 682])
       increase the inter-escape segment length by a factor of 2 or 3 each round,
       so floor(log2(seg)) increments by +1 each round and rsigb[ns-1] == rsigb[ns-2]
       never triggers before --maxt = 6e6 expires.
     - Period-2 or multi-jump rebuilds (such as zeros = [9 8 69 68 129 128 ...])
       alternate between two escape signatures (e.g. "j0," and "j-1,j0,") because
       only consecutive entries rsigs[ns-1] == rsigs[ns-2] are compared.
  2. Blank-Tape Phantom-Zero Bug for BE == 0, S_ == "0" Templates (wf.cpp lines 145-171):
     - When BE == 0 and S_ == "0" (template d = 1d+0, s = 0, where digit d = 0 is
       a single '0' cell), kmoment() scans all the way to W.lo (the historical
       extremum of the tape). Any blank '0' cell between W.lo and the leftmost '1'
       on the support of the tape is parsed as a leading 0 digit (tok.back() == 0).
     - Furthermore, at each waterfall jump (line 169), wf.cpp writes k + 1 zeros
       starting at W.lo. If the next rebuild only reaches width k' < k, the
       leftover k - k' blank '0' cells in [W.lo, leftmost_1) are parsed as k - k'
       phantom 0 digits at the next K-moment!
     - This produces the fake countdowns seen on Base 546 (zeros = [66 65 64 .. 0]),
       Base 672 (zeros = [3 2 1 0 270 269 ..]), Base 608 (zeros = [423 421 ..]),
       Base 190/297/366/367, and Base 429 (zeros = [..68^29 6^10 125]), as well
       as off-by-one distortions of k when 1 cell at the far end of the tape is
       erased before a jump.
     - Fix (implemented in scratch/wf_sum.cpp):
       if (BE == 0 && S_ == "0") { while (tok.size() > 1 && tok.back() == 0) tok.pop_back(); }
