WHAT WORKS (tools in this folder; see NOTES.md for the log and all bug fixes)
  wf.cpp -> wf8.exe  world follower derived from bb8_resid/tools/zfg7.cpp. It runs the TM literally. At each K-moment
    of the base's dlscan template it clears the near token list in one jump and sets the accumulator to
    R = rc + k, rounded up into the base's tower class mod 60, with the first R = the class representative.
    Extras over zfg: O=L templates (by mirroring); tail forms S1 W^t S2 (M8's (11111100)^t); a counter for reads of
    the redirected slot; an escalation counter (k > max k and k >= 0.5 * max previous R); slot and pair bookkeeping;
    snapshots; batch mode; TNF-style lazy branching of H0/H1; a jump-level accelerator (periodic-run compression,
    4 iterations with constant run deltas, needed for M8's counter modes); and round-signature LOOP detection.
    Budgets are split into an exact phase and a world phase.
  towercls.py  refits each base with reb7 fit7 and evaluates deep clearings with eng7 (mod 80640). It gives the
    tower class mod 720 for all 716 bases: 655 have one class, 61 have two or three. The champion gives 366 mod 720,
    which matches the known 366 mod 3600.
  screen.py (tier 1), tier.py (tiers 2/3), collect.py (merge and rank), launch.py (Idle priority; PIDs go to
    pids.txt).
