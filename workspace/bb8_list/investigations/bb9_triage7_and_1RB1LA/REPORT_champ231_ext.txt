1.2 Proof of the Global Parity Invariant & 2-Adic Contraction (`compute_A1_mod_powers_of_2.py`)
-----------------------------------------------------------------------------------------------
**Lemma 1 (Global Parity Invariant)**:
Define `I(d_k, ..., d_1; a) := (a + sum_{i=1}^k d_i) mod 2`. Then `I` is invariant
under every `D` step and every `B_m` step:
  - Under `D`: `d_1 -> d_1 - 1` and `a -> 3a + 3 == a + 1 (mod 2)`, so
    `Delta I = -1 + 1 = 0 (mod 2)`.
  - Under `B_m`: `y+1 -> y` (`-1`), `0 -> 3a + 3 - m` (`+3a + 3 - m`),
    `0^(m-1) -> 1^(m-1)` (`+m - 1`), and `a -> 1` (`+1 - a`), so
    `Delta I = (-1) + (3a + 3 - m) + (m - 1) + (1 - a) = 2a + 2 == 0 (mod 2)`.
Consequently, if `K(d_k, ..., d_1; a_init; 0)` reduces to `K(0^k; A_final; 0)`, then:
    A_final == a_init + sum_{i=1}^k d_i  (mod 2).

**Lemma 2 (2-Adic Contraction Theorem)**:
Immediately before `K(0^k; A_final; 0)` is reached, the last borrow `B_1`
transitions `K(0^(k-2), 1, 0; a_prev; 0) -> K(0^(k-1), d_1; 1; 0)` with
`d_1 = 3*a_prev + 2`, followed by `D^(d_1)(1)`:
    A_final = (5 * 3^(d_1) - 3) / 2.
Because `v_2(3^d - 1) = v_2(d) + 2` for even `d`, the map
`a_prev -> (5 * 3^(3*a_prev + 2) - 3) / 2` is a 2-adic contraction with
Lipschitz constant `1/2` on `Z_2` that flips parity (`A_final == a_prev + 1 (mod 2)`).
Therefore, for any tower of height `k >= r`, `A_final mod 2^r` depends ONLY on
the parity invariant `I = A_final mod 2`:
  - **Odd fiber (`I = 1`)**:
    Since `A_final` is odd, `a_prev` is even, so `d_1 = 3*a_prev + 2` is even.
    In fact `a_prev == 2 (mod 4) => d_1 == 0 (mod 4) => 3^(d_1) == 1 (mod 16)`,
    giving `A_final == (5*1 - 3)/2 = 1 (mod 8)` and `A_final == 9 (mod 16)`.
  - **Even fiber (`I = 0`)**:
    Since `A_final` is even, `a_prev == 1 (mod 8)` is odd, so `d_1 = 3*a_prev + 2 == 5 (mod 8)`,
    giving `A_final == 2 (mod 4)`, `6 (mod 8)`, and `14 (mod 16)`.
