- **Slot Usage**:
  - In all 7 variants, `Blank -> F([2,2], 0)` and `R1: F([2,2], 0) -> F([1,2], 1)`
    use **all 15 defined transitions** (`A0..G1, H1`).

    everything except `G0`).
  - Therefore, there are **zero** `R4`-only transitions (`Slots in R4 \ (R1 U R3A) = empty`).

- **9-Cell Local Context Theorem**:
  - Comparing every `(state, read_bit, tape[h-r .. h+r])` context visited during
    `R4` (`F([0], b)` for `b = 2, 3, 14`) against those visited during
    `Blank -> F([2,2],0)` + `R1` (on 2-digit `F([d1,d2], b)` and 1-digit `F([d1], b)`,
    which occurs throughout Epoch 1 `F([14], 0) -> ... -> F([0], 14)`) + `R3A`:
      * `r = 1` (3-cell window): **0** contexts in `R4 \ (init + R1 + R3A)`
      * `r = 2` (5-cell window): **0** contexts in `R4 \ (init + R1 + R3A)`
      * `r = 3` (7-cell window): **0** contexts in `R4 \ (init + R1 + R3A)`
      * `r = 4` (9-cell window): **0** contexts in `R4 \ (init + R1 + R3A)`
  - Reason: Because a zero digit in `1RB1LA` is `00` with no left boundary prefix
    (`P = -`), `PassB` (stepping left into blank tape `0^inf` at the start of `R4`)
    sees the exact same local `000` cells as `Pass` (stepping left into a `00`
    digit during `R3A`), and `R4_1` (finishing at the left end of the tape) sees
    the exact same left-end blank boundary as 1-digit `R1` (`F([d], b)` in Epoch 1).
