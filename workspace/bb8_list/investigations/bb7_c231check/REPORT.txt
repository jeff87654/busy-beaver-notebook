4. SCORE (paper proof)
  Let f(x)=3x+3=U_0(x), s_0=1, s_j=U_{j-1}(s_{j-1}), and U_j(x)=U_{j-1}^(3x+3-j)(s_{j-1}).
  This is "one unit of digit j+1": B_j, then clearing digits 1..j.
  Then a_f = U_19(U_18(...U_1(8))) and sigma = 6 a_f + 7.
  Lemma: U_j(x) >= 3↑^j (3x+3-j) for 1<=j<=20. Proof:
  - U_1(x) = f^(3x+2)(1) >= 3^(3x+2).
  - Induction step: U_{j-1}(y) >= 3↑^{j-1} y on all iterates (2y >= j-4 holds, since every iterate from s_2 on is huge).
    Hence U_{j-1}^n(s) >= (3↑^{j-1})^n(1) = 3↑^j n.
  Chain:
  - x_1 = U_1(8) = (5*3^26-3)/2, so 3x_1+1 > 3^27 = 3↑↑3.
  - x_2 >= 3↑↑(3x_1+1) >= 3↑↑↑3.
  - x_{j+1} >= 3↑^{j+1}(3x_j+2-j) >= 3↑^{j+1} x_j >= 3↑^{j+2} 3.
  - So a_f = x_19 >= 3↑^20 3, and sigma > 3↑^20 3.
  Heuristically a_f lies between 3↑^20 3 and 3↑^20 4. Only the lower bound is claimed.
  Comparisons:
  - BB(7) champion: sigma > 2↑^11 2↑^11 3 (wiki); 3*(2↑^13 3)+22 in our COMPARISON.md. Both are < 2↑^14 3 <= 3↑^20 3.
    Beaten.
  - BB(8) M8: f_w(f_w(12B+26)) < sigma(M8). This machine is ~f_21(small), which is << f_w(12). Not beaten, not close.
    A 7-state machine also does not need to beat it.
