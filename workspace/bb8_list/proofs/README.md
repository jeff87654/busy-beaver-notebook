# Machine-checked proofs (busycoq)

Formal non-halting proofs for individual machines. They use
[busycoq](https://github.com/meithecatte/busycoq) (`../../third_party/busycoq`, commit `bd2e36f`, unmodified),
the library behind the individual-machine proofs in the Coq proof of BB(5).

## Toolchain
- Coq 8.20.1 (Coq Platform 2025.01.0, installed at `C:\Coq-Platform~8.20~2025.01`, INRIA-signed installer).
  Coq-BB5 was built with the same version.
- `python build.py [File.v ...]` compiles busycoq dependencies and our files with `coqc` (no make needed).
  Logical paths: `BusyCoq` = busycoq `verify/`, `BB8` = this directory.
- Setup files: `BB72.v`/`Individual72.v` and `BB82.v`/`Individual82.v` instantiate busycoq for 7 and 8 states.
  They mirror upstream `BB52.v`/`Individual52.v`.
- `Smoke82.v` is a minimal 8-state example.

## Writing a proof
- File name: `BB<n>_<subtask>_<first 6 chars of machine>.v`.
- Required shape; see `Smoke82.v` and upstream `Skelet33.v`, `Finned1.v`:
  ```coq
  From BB8 Require Import Individual82.        (* or Individual72 *)
  (* machine: <standard TM string, e.g. 1RB1LD_..._1RD1LG> *)
  Definition tm : TM := fun '(q, s) => match q, s with | A, 0 => Some (1, R, B) | ... | _, _ => None end.
  ...
  Theorem nonhalt : ~ halts tm c0.
  ```
- Tactics: `execute` (run concrete steps), `follow <lemma>` (apply a proven rule), `triv`, `start_progress`.
- Tape notation: `l {{A}}> r` / `l <{{A}} r`, `const 0`, `[1;0] *> r`, `xs ^^ n`.
- Finish with `multistep_nonhalt` plus `progress_nonhalt_simple` or `progress_nonhalt_cond`.
- `H` is a state name in the 8-state setup, so name hypotheses something else (e.g. `Hx`).

## Checking a proof
`python check.py <File.v>` accepts `Theorem nonhalt : ~ halts tm c0.` or `Theorem halt : halts tm c0.`:
1. compiles the file;
2. verifies the transition table equals the declared machine string. Coq itself evaluates `tm (q, s)` for every entry, so text in comments cannot mislead it;
3. has Coq type-check the theorem against the exact statement;
4. requires `Print Assumptions` to report "Closed under the global context" (no `Admitted`, no axioms).

After a PASS, the only human review needed is that the declared machine string is the intended machine.
